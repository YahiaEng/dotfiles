## What shipped

**One shell.** Every remaining pre-Quickshell surface is now QML, redesigned toward the
end-4/Caelestia reference language rather than straight-ported, and each old package was
deleted in the same phase that proved its replacement.

- **QBAR (12 reqs)** — the bar is a Quickshell surface in all four layouts, reserving its
  own screen space, with workspace click restored. That click was permanently dead under
  waybar 0.15.0, compiled into `Workspace::handleClicked` and unreachable from config; the
  bug class was removed structurally rather than patched, since QML uses the GlobalShortcut
  protocol and has no IPC dispatch strings at all.
- **QNOTIF (11 reqs)** — the shell *is* the session's `org.freedesktop.Notifications`
  server: popups with swipe-dismiss, in-place `replaces_id` updates, working action buttons,
  a slide-out centre with grouped history, and DND surviving a shell restart.
- **QOSD (4) / QPOWER (4)** — volume/brightness/caps-lock indicators and the power menu,
  both in-process.
- **QMEDIA (3)** — the standalone GTK4 media applet folded into the dashboard's Media tab at
  16/16 checklist parity, with the cava visualiser restored as a 60-bar radial ring.
- **RETIRE (9)** — waybar, swaync, swayosd, wleave and ags deleted from repo *and* host;
  `wlogout`/`eww` uninstalled; `contract.json` down from 29 to 17 entries.
- **GATE (8) / LEDGER (8)** — the quality-gate machinery and the full v3.0 debt ledger.

## What the milestone proved about itself

**Phase 22 was the closing regression gate, and its most valuable output was not the pass.**
The gate proved a clean clone reproduces the whole themed desktop — container tier
`overall=PASS` across nine gating steps, graphical VM tier passed by human verdict with zero
exemptions invoked. But getting there required repairing the harness first, and that repair
is the durable artifact:

- The `timeout` wrapper **never stopped its container** under rootless podman — it detached
  the client while conmon kept the container alive, which is how one run wrote *two*
  independent `overall=` verdicts into the same log. The phase's own `T-22-01-DOS`
  mitigation claim was falsified by direct measurement and superseded.
- The gate went from **~62 minutes to ~17**, once per-package timing showed 43 of those
  minutes were two icon-theme packages doing small-file I/O onto overlayfs.
- A new dangling-symlink checker reported **1095 findings** against the real host, of which
  1085 were the checker looking outside its own declared scope — and 5 were its own
  deliberately-poisoned test fixtures, which stow deploys to every machine. Left alone,
  `theme-doctor` could never have passed on any fresh install.
- The close-out review found **two Critical false-PASS bugs** in the newest gating code:
  `stow-link-check` reporting `0 passed, 0 failed` and exit 0 when python3 was absent, and
  `container-run.sh` capturing `theme-doctor`'s exit code without ever checking it. Neither
  had fired — but both lived in code that had only ever been exercised on a passing run.

The recurring lesson, stated once here because it earned its place three separate times:
**a gate that has only ever been green has not been shown to reject anything.**
