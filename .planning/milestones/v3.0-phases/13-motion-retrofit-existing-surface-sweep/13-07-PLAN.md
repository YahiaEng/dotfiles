two moves:
1. **Re-map to a different token** — a different easing from the primary-sourced scale, or a
   different duration from the MD3 duration table, or both. This is the default and covers
   most complaints: "too slow" is a duration change, "wrong settle" is an easing change.

   source. This is the one sanctioned landing spot for a motion whose complaint is
   specifically the missing overshoot character, because the primary-sourced data confirms the

   name is by definition not a one-off, which is what makes this legitimate rather than a
   loophole.

policy forecloses, and it is what makes the character-curve deletion irreversible by design.

marked set in the token source with a comment naming why, and reference it — one definition,
many references.

because Task 3 deletes every `x-*` entry that no motion adopted and needs an authoritative
list of which ones survive.

and `hyprctl animations -j` confirming each retuned slot holds its new values rather than a
