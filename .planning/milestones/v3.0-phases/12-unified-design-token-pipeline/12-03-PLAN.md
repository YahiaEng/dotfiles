<objective>
**Tracer.** Wire one hand-authored motion-token source through a new `motion.sh` emitter to
all three render targets, end to end, through `theme-apply`'s existing single entrypoint —
then bring the emitted files fully inside `contract.json`'s manifest and close D-29's
engine-owned-state bug class.

Purpose: this is the phase's architectural spine. It proves the whole shape on one real
`theme-apply` run before any consumer is built on it: source -> transform -> three formats ->
atomic commit -> manifest -> gates. Every later plan in this phase expands outward from this
slice. It is production-quality, not a prototype — the emitter it creates is the one that
ships.

Output: `motion.json`, `lib/motion.sh`, three rendered targets under `~/.local/state/theme/`,
four `contract.json` amendments, two new `contract.sh` format branches, a `commit.sh` that
derives its exclusions from the manifest, and a `theme-doctor` gate that refuses an
undeclared state file.
</objective>
