<objective>
Prove the live-wallpaper architecture end-to-end, once, on one path, before any expansion plan is built on it.

This is the phase's tracer: a real video in `~/Pictures/Wallpapers/<theme>/live/` plays beneath the desktop through a production-quality single-owner script, and actually stops decoding when a client goes fullscreen. Every layer criterion 1 names is touched — package provisioning, on-disk layout, the sole-owner arbitration script, the external player, the compositor protocol — with nothing stubbed and nothing mocked.

Purpose: D-26's shipping-vs-fallback branch is the one decision the whole AMB-01 track assumes is settled. RESEARCH.md verified both ends of that protocol at the exact installed commit but could never run it (mpvpaper is not installed). This plan installs the binary and closes the gap by running it, so an architectural dead end surfaces after one commit rather than after the picker, the frame extractor and the suppression states are all committed on top of it.

Output: `mpvpaper` declared as a hard dependency; the `live/` layout reproducing from `stow.sh`; `wallpaper-visibility.sh` as the sole owner of the player's lifecycle; a recorded verdict on the D-26 probe; a recorded user decision on the `-a` mode; and proof that animated GIF and animated WebP behave as live wallpapers, not stills.

**Precedence note (RESEARCH.md corrects CONTEXT.md):** D-26's framing that mpvpaper's hide mechanism is "at best a hack" applies only to bare `-p`, which uses a frame-callback deadman timer. `-a full` is a completely separate, protocol-based code path (`wlr-foreign-toplevel-management-unstable-v1`), and Hyprland 0.56.2's compiled `ForeignToplevelWlr.cpp` implements the FULLSCREEN/MAXIMIZED state events at the exact installed commit. Ship `-p -a full`; D-27's watcher stays a scoped safety net, not a co-primary. Do not carry the "hack" framing forward.

**Scope boundary — what this plan deliberately does NOT do.** Frame extraction, `current.jpg`, `contract.json`, the `last-wallpaper` validator widening and `theme-doctor` are 17-02. The picker, `theme-apply`/login wiring, the three suppression states (idle/gaming/reduced-motion), the `quickshell-doctor` layer assertion and the blocking human render-and-look gate are 17-03. This plan wires ONE entry point (a direct CLI invocation of the owner) through every layer. It declares the owner's three suppression source names because the compute function's union is architecture, but it wires no call sites for them — that is expansion, not tracer.
