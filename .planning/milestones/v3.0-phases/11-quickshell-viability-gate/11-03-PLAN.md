<objective>
Build `quickshell-doctor`: the rerunnable gate that mechanically proves Quickshell coexists with the six live GTK surfaces, and that keeps proving it as Phases 14, 15 and 16 add more.

Purpose: D-05's core argument is that a one-shot manual record would silently rot. Phases 14, 15 and 16 each add a surface and/or a keybind; without a standing gate, the Phase 11 coexistence claims decay into folklore. This is the repo's seventh gate script and it sits alongside `theme-doctor`, `theme-parity`, `theme-stress-test`, `keybind-doctor`, `waybar-equivalence-check` and `waybar-design-lint`, following their shared house style so it is legible to anyone who has read one of them.

It also corrects a schema error the roadmap inherited: `hyprctl layers -j` on Hyprland 0.56.0 carries **no exclusive-zone field at all**. A check written against the roadmap's literal wording would always report PASS. The real reservation data lives in `hyprctl monitors -j`'s `reserved` array.

Output: `hypr/.config/hypr/scripts/quickshell-doctor`, run green against the live desktop, with its results dated into the evidence artifact.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Compositor / session-bus output → gate parser | `hyprctl`, `busctl` and `pactl` output is parsed field-by-field and drives pass/fail decisions |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-10 | Tampering | Manifest-derived values interpolated into `hyprctl dispatch global <appid>:<name>` | high | mitigate | `shortcuts.json` ships inside a stow package and is therefore repo-controlled, but it is still parsed input crossing into a command invocation. Validate `appid` and `name` against a strict character allowlist (alphanumeric, `-`, `_`) before either value reaches a command line, and pass them as separate argv elements rather than through a shell string. Never `eval` a constructed dispatch line. |
| T-11-11 | Denial of Service | The volume probe leaving the user's audio muted or at a wrong level | medium | mitigate | Install the restore trap on EXIT/INT/TERM *before* the first mutation, not after; restoration is the trap's job alone so an interrupt between mutate-and-restore cannot strand the user. Skip cleanly with a named `[SKIP]` when no default sink exists. Acceptance criteria assert the volume is byte-identical before and after a full run, including under SIGINT. |
