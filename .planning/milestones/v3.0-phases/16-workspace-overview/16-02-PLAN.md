<objective>
The tracer: one production-quality path from keypress to live pixels and back to
the desktop, wired through every layer this phase will touch, with nothing else
built on top of it yet.

Super+O → Hyprland Lua bind → declared shortcut manifest → shell root LazyLoader →
a full-screen `quickshell-overview` layer surface → `Hyprland.focusedWorkspace` →
that workspace's `toplevels` → one live `ScreencopyView` per window at its real
scaled geometry → click to focus the workspace and close → destroy-on-dismiss.
Plus the `overview` IPC verb, because "the thumbnails have content" has to be
checkable without a human squinting at a screenshot.

This is one tile, not eleven. That is the point: it proves the architecture
end-to-end on the phase's best early-context tokens, so an architectural
dead-end shows up after one commit instead of after the whole grid, the drag
grammar and the keyboard model are already committed. It is not a prototype —
every line here survives into the shipped surface; plan 16-03 expands the single
tile into D-16-01's fixed grid without rewriting it.

Purpose: OVER-01 and OVER-02 both become demonstrably true on a thin path before
anything is built out horizontally.
Output: five new/changed QML+config files, a fifth shortcut manifest entry, a
`quickshell-overview` fade layer rule, and a human-attested first sighting of
live thumbnails.
</objective>

**`modules/overview/WorkspaceTile.qml`** (new): an `Item` exposing
`property var workspace` (a `HyprlandWorkspace` or null), `property real

neighbours. Background is a `Rectangle` filled `Colours.surface`, radius from a

precedent), border `Design.borderWidth` in `Colours.outline`. Inside it, a
`Repeater` over `workspace ? workspace.toplevels : null` whose delegate is an
`Item` positioned at `(modelData.lastIpcObject.at[0] - monitorX) * captureScale`,
`(modelData.lastIpcObject.at[1] - monitorY) * captureScale`, sized
`modelData.lastIpcObject.size[0] * captureScale` by
`modelData.lastIpcObject.size[1] * captureScale`, containing a `ScreencopyView`
with `captureSource: modelData.wayland` and `live: true`. `monitorX`/`monitorY`

one display. Guard every `lastIpcObject` read against null and against a missing
`at`/`size` field — a toplevel can exist before its IPC object lands.

<assumption_delta_decision>
**Signal:** `pluralization` on *another* ("Dragging a window thumbnail onto
**another** workspace tile moves that window there") and on *fallback*
("…either stays inside it or ships the documented **fallback** instead").

**The noun that is now primary.** Before this phase the shell had no identity for
an individual window at all, and "workspace" only ever meant *the one you are on*.
This phase makes both plural and addressable: the primary key for every operation
here is **(window identity, workspace-target token)** — `HyprlandToplevel.address`
paired with a workspace token that is either an integer `1..10` or the literal
`special:magic`.

**Decision: `promote`.** The addressed pair becomes primary and "the focused
window on the current workspace" is demoted to one *instance* of it. The concrete
payoff is D-16-05's scratchpad: under the promoted model `special:magic` is an
ordinary member of the workspace-target set, so drag-in and drag-out are the same
code path as any numbered tile. This tracer already honours the promotion in the
one place it can: `WorkspaceTile` takes a `workspace` *property* rather than
reading `Hyprland.focusedWorkspace` internally, so plan 16-03 instantiates eleven
of them without touching the type.

**Second signal — render mode.** Decision: `promote` as well — the thumbnail is
the general representation and carries the capture mode as a variant; `live: true`
is one variant, not the primary with snapshot bolted on. D-16-11 bakes exactly one
mode into the shipped build, but the representation stays general, which is what
makes D-16-07's ladder a property change rather than a second renderer. This
tracer keeps the `ScreencopyView` in exactly one type (`WorkspaceTile`'s delegate,
extracted into `WindowThumbnail` by plan 16-03) rather than scattering capture
across the surface.

**Suggested invariant test (not required by this plan):** a `quickshell-doctor`
source check asserting `ScreencopyView` is instantiated in exactly one file. It
goes red the instant a future phase reintroduces a second, singular capture path.
Plan 16-04 is the natural home for it.
</assumption_delta_decision>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client windows → overview surface | Live pixel content of every window on the workspace — possibly a password manager, a private message, a banking page — is rendered onto a shell-owned surface |
| any local process → `qs` IPC socket | `qs ipc call overview toggle` is reachable by anything running as this user; it can summon the surface and therefore start captures |
| Hyprland compositor → quickshell | The compositor decides whether `/usr/bin/quickshell` may capture at all (`permissions.lua`, still inert this plan) |
| Hyprland Lua evaluator → keybind file | `keybinds.lua` is evaluated as Lua source at compositor start |
