<objective>
Add the icon-theme axis (UTIL-04): an fzf-in-kitty picker over installed icon themes that applies live to Thunar/GTK, persists as a theme-orthogonal state axis surviving theme switches, and tracks folder accent colors to the palette (Papirus via papirus-folders, Tela/Colloid via nearest-variant swap). Closes Pitfall 6 (the currently-hardcoded gtk-icon-theme-name=Adwaita would silently revert any pick on the next switch).

Purpose: Icon themes did not exist as a concept in this pipeline before Phase 6. The picker must not bare-gsettings-set (Pitfall 6) — it writes state and re-runs theme-apply, and generate.sh reads that state into the rendered settings.ini so switches never clobber it. This plan owns generate.sh/commit.sh/gtk.sh for Wave 2.
Output: icon-theme-picker.sh, gtk.sh icon function, generate.sh state read, commit.sh exclude.
</objective>
