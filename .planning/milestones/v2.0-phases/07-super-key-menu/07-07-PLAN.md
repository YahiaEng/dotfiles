<objective>
Build the Game Center (MENU-04): a four-launcher submenu plus the reversible, session-scoped Gaming mode toggle.

Purpose: Greenfield — nothing gaming-related is installed. The launchers are trivial; the toggle is not. It suppresses the lock screen, which is a real physical-access exposure if it ever fails to reset — which is precisely why D-28 forces reset-to-OFF on session start. And it must be runtime-only: this project has a theme pipeline that OWNS the Hyprland config files, so a toggle that rewrote them would desync the pipeline and produce exactly the class of bug the theme-engine consolidation exists to kill.
Output: A 5-entry Game Center submenu, a reversible gaming-mode toggle, a session-start reset hook, and a stow-seeded state file.
</objective>
