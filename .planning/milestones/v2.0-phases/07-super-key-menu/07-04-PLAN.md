## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| physical keyboard → Hyprland keybind engine | A rebind of the primary modifier key. A mistake here is a self-inflicted denial of service against the user's only input device — the highest-severity failure mode in this phase. |
| `bindr` release-bind → all 48 existing combo binds | The shadowing behaviour is the security-relevant property: a non-shadowed release bind would fire an unwanted action on every single Super combo. |
