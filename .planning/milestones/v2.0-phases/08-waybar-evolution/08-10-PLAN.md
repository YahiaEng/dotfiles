**PART A — the exposure ratio (does D-01's auto-hide actually remove the bar's on-screen time?).**

Sample the owner's own computed state over a **real, mixed-usage working session**, then compute a weighted exposure ratio.

  - **Instrument.** A throwaway sampling loop (do not add a permanent script to the repo — this is measurement, not a feature). **PART B — the luminance delta (did D-06's trim actually reduce what the bar emits?).**

Measure it photometrically off the real screen. All required tooling is verified installed: `grim` 1.5.0, `imagemagick` 7.1.2, `python-pillow` 12.3.0, `python-numpy` 2.5.1, `jq` 1.8.2.

  - **Geometry.** Read the bar's live region from `hyprctl layers -j` (the `waybar` namespace entry — `x`/`y`/`w`/`h`; verified on this machine as `x=0 y=0 w=2560 h=37`). Feed that rectangle to `grim -g` so the capture is exactly the bar and nothing else. Do not hardcode the geometry; a different layout or monitor changes it.
  - **The metric — and the one way to get this wrong.** Compute **relative luminance** with the Rec.709 coefficients (0.2126·R + 0.7152·G + 0.0722·B) applied to **linearised** sRGB channels — i.e. undo the sRGB transfer function *before* averaging.
