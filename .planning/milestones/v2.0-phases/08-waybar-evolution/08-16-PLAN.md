<design_system>
The binding contract is `08-athena-DESIGN.md`. Key rules restated for execution:

**Rule 1 — colour is matugen-per-theme, always.** No literal hex anywhere. No per-app brand
colours. Every colour is a theme.css role name. `waybar-design-lint` CHECK B (role names only
outside theme.css) and CHECK D (no literal hex) must pass for config-athena.jsonc and
style-athena.css.

**Rule 2 — capsules are the identity.** Each module-group is a discrete rounded pill on a
raised neutral surface. The window itself stays transparent (CHECK C). The palette lacks
`surface_container`; the capsule surface is a NEW theme.css alias `@capsule` built on
`@surface_variant` (the only distinctly-raised neutral token this palette has). Capsule glyph
colour is `@capsule-fg` = `@on_surface_variant` (the legible dimmed role — NEVER `@outline`,
which is the 08-12 illegibility bug).

**Rule 3 — chroma encodes state + focus only.** `@accent` on the active workspace pill and on
app-drawer hover. `@warn`/`@danger` on cpu/mem/disk/temp warning+critical, idle-inhibitor
active, network disabled. Everything else at rest is `@capsule-fg` or `@fg`. No decorative hue.

**Rule 4 — Athena's arrangement, this system's modules.** Left: app-drawer, storage pill
(disk+memory), system pill (temp+cpu). Center: workspaces (live window icons), idle_inhibitor.
Right: audio drawer (pulseaudio + slider + mic), connections drawer (network+bluetooth), clock
pill, tray group (swaync bell + tray + theme-switch + layout-switch folded into its drawer),
gaming-mode + power. DROP battery (desktop) and power-profiles-daemon (inactive).

**Rule 5 — every glyph cmap-verified.** Per 08-11: zero empty/whitespace glyph fields; every
codepoint present in FiraCode Nerd Font. `waybar-design-lint` CHECK E enforces this.

**Rule 6 — the rename is complete.** `git mv` config-minimal.jsonc -> config-athena.jsonc and
style-minimal.css -> style-athena.css, then rewrite. Grep the whole repo for other hardcoded
"minimal" references (docs, stow, theme-doctor expected-layout lists) and update or remove
them. The switcher auto-enumerates config-*.jsonc, so no switcher edit is needed, but a stale
"minimal" string elsewhere will lie about a layout that no longer exists.
</design_system>
