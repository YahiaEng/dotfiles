  <action>
Create `media-art-resolve.sh`: a one-shot resolver that takes an `mpris:artUrl` as `$1` and prints a local, readable, image-content-verified file path on stdout, or prints nothing and exits non-zero. Taking the URL as an argv parameter (rather than calling playerctl itself) is deliberate: it makes every adversarial branch directly testable without a running player, which Task 3's gate depends on.

Boxed header names BAR-04 / D-21 and states the hard constraint: the argument is UNTRUSTED third-party D-Bus data and must never be re-parsed as code. `set -euo pipefail`.

Tunable constants at the top: `CACHE_DIR="$HOME/.cache/eww-media-art"`, `MAX_BYTES=5000000`, `TIMEOUT_SECS=5`.

Behaviour, in order:

1. **Arity + charset guard.** Exactly one argument. Reject (exit 2, print nothing) if it is empty, longer than 2048 characters, or contains any C0 control character or newline — strip/test with a bracket-expression check, never by re-evaluating the string.

2. **Scheme allowlist (T-08-07-03/04).** Extract the scheme with bash parameter expansion / a case pattern — not a subshell. Accept exactly three: `file://`, `http://`, `https://`. **Everything else (ftp, data, gopher, javascript, a bare path with no scheme, a scheme with embedded whitespace) exits 3 with no output and no filesystem or network side effect.** This is the single most important line in the file.

3. **Cache dir.** `mkdir -p` the cache dir and `chmod 700` it. If the path exists but is not a directory, or is a symlink, exit 4 rather than following it.

4. **`file://` branch (the verified Zen/Firefox case).** Strip the `file://` prefix, percent-decode `%XX` sequences (use `printf '%b'` on a `%`→`\x` substitution, or a `python3 -c` urllib call — either is fine; do NOT shell out to anything that re-parses the decoded string). Then: `realpath -e` the result to canonicalise and resolve symlinks; require it to be a regular file (`-f`) and readable (`-r`); require `file --mime-type -b` on it to report a type beginning with `image/`. Print the canonical path, exit 0. A path pointing at a non-image (a key, a config, a device node) fails the mime gate and exits non-zero — this closes the arbitrary-local-file-read vector without needing a directory allowlist.

5. **`http(s)://` branch (Spotify, Assumption A2).** Compute the cache key as the sha256 of the FULL url: pipe the url into `sha256sum` via a here-string, take the first field. Cache path is `$CACHE_DIR/<sha256>` — no extension, no player-supplied component anywhere in the filename (T-08-07-05).
   - **Host guard:** extract the host portion and reject (exit 3) the obvious internal targets before any network call: `localhost`, any `127.*` / `::1` / `0.0.0.0` literal, `169.254.*`, `10.*`, `192.168.*`, and `172.16.*`–`172.31.*`. Syntactic check only — document in a comment that this is a best-effort SSRF guard, not a DNS-rebinding-proof one.
   - **Cache hit:** if the cache path already exists AND is a regular file (not a symlink — if it is a symlink, unlink it and treat as a miss) AND passes the same `image/` mime gate, print it and exit 0 with no network call.
   - **Cache miss:** download into a `mktemp` file created INSIDE `$CACHE_DIR` with `curl -sfL --no-netrc --proto '=http,https' --proto-redir '=http,https' --max-time "$TIMEOUT_SECS" --max-filesize "$MAX_BYTES" -o "$tmp" -- "$url"`. The `--` guard before the url is mandatory (it stops a url beginning with a dash from being read as a curl flag). Trap-clean the temp file on any exit path.
   - Mime-gate the downloaded bytes (`file --mime-type -b` must report `image/`); on failure, delete the temp file and exit non-zero — a non-image response body never enters the cache. On success `chmod 600` then `mv` the temp file onto the cache path (atomic, same-filesystem), print the cache path, exit 0.

6. Every failure path prints nothing on stdout (the caller treats empty output as "no art") and writes at most a one-line diagnostic to stderr. There are no `notify-send` calls in this script.
  </action>

**A. `media-players.sh` — the player-name allowlist owner and the ONLY control dispatcher.**

Boxed header names D-21 / D-25 and states the hard constraint: a player's D-Bus bus name is attacker-influenced and is the ONLY metadata-derived string this repo ever allows near a command invocation — so it is validated once, here, and nowhere else. `set -euo pipefail`. State file constant: `SELECTED_FILE="$HOME/.cache/eww-media-player"`.

Central private function `_valid_id`: returns 0 only if the candidate matches `^[A-Za-z0-9._-]{1,128}$` (a bash `[[ =~ ]]` test — no subshell, no external command). Any id failing this is dropped silently from listings and rejected with a non-zero exit from `cmd`/`select`. This one regex is the mitigation for T-08-07-02.

Subcommands (dispatched from a `main()` case, exactly like `gaming-mode-toggle.sh`):
- `list` — run `playerctl -l 2>/dev/null || true`, filter every line through `_valid_id`, and emit a JSON array via `jq -R -s -c` + a `map` that builds `{id, label, active}` per entry. `label` is the UI-SPEC display rule: strip a trailing `.instance_<digits>` suffix, then capitalise the first character. `active` is true for the id equal to the current selection. Always exits 0; prints `[]` when nothing is running.
- `active` — print the effective player id and exit 0, or print nothing and exit 1 when there is none. Effective = the id in `$SELECTED_FILE` **if** it still appears in `playerctl -l` and passes `_valid_id`; otherwise the first valid id from `playerctl -l`; otherwise nothing. **This exit code is D-25's gate and 08-08's contract — an empty player list must exit 1.**
- `select <id>` — validate with `_valid_id` (exit 2 on failure, write nothing), then persist with the `gaming-mode-toggle.sh` atomic idiom (`printf '%s\n' "$id" > "$f.tmp" && mv "$f.tmp" "$f"`).
- `cmd <id> <action> [arg]` — the ONLY place playerctl is invoked for a mutating action. Validate `<id>` with `_valid_id` (exit 2). Validate `<action>` against a literal case allowlist: `play-pause`, `next`, `previous`, `seek`, `volume` — anything else exits 2. For `seek` and `volume`, require `[arg]` to match `^[0-9]+(\.[0-9]+)?$` (exit 2 otherwise), then invoke argv-form: `playerctl --player="$id" position "$arg"` for seek, `playerctl --player="$id" volume "$arg"` for volume. For the three transport verbs, invoke `playerctl --player="$id" <verb>`. Every invocation is a direct argv call with quoted variables — the command string is never assembled from data and never handed to a shell for re-parsing.
<!-- planner-discipline-allow: eval -->
- No form of string-to-code re-evaluation (`eval`, `sh -c "$var"`, backtick expansion of data) appears anywhere in this file. Guard `playerctl` failures with the house `2>/dev/null || true` where a failure is benign (a player that vanished mid-click).

**B. `media-status.sh` — the single-line JSON payload contract.**

Boxed header names D-21 / D-25 and states the hard constraint: every string field originates in a third-party player and is emitted through `jq --arg` — never through string concatenation, never into a shell command. `set -euo pipefail`. Tunable constant `POLL_INTERVAL=1` (seconds) at the top — CONTEXT explicitly grants polling strategy to Claude's discretion, and a 1 Hz change-detected poll is chosen over a `playerctl -F` follower because re-targeting on a player switch is then free (each tick simply re-reads the selection).

Subcommands:
- `once` — resolve the effective player via `media-players.sh active`. If that exits 1, emit the **empty payload** (all string fields `""`, numeric fields `0`, `volume` `-1`) and exit 0. Otherwise query playerctl **once per field, never with a multi-field format template** (a delimiter-joined template is unsplittable when a title legitimately contains the delimiter): `status`, `metadata xesam:title`, `metadata xesam:artist`, `metadata xesam:album`, `metadata mpris:artUrl`, `metadata mpris:length`, `position`, `volume` — each guarded with `2>/dev/null || true` so a missing property yields an empty string rather than aborting the script.
- Sanitise every string field before it leaves the script: delete C0 control characters and newlines (`tr -d '\000-\037'`), then truncate to 200 characters. This closes the newline-injection vector that would otherwise let one player emit two JSON lines and desync `deflisten`'s one-object-per-line protocol (T-08-07-07).
- Resolve art by calling `media-art-resolve.sh "$art_url"` and capturing stdout (empty on any failure — the popup then shows its glyph fallback instead of an image). Never pass the raw artUrl to eww.
- Compute `length` seconds as the `mpris:length` microseconds integer divided by 1000000 (integer division, 0 when absent); `position` is playerctl's float seconds rounded down to an integer. `volume` is playerctl's float, or `-1` when the player exposes no volume property (Firefox/Zen commonly does not — a `-1` tells the widget to hide the slider row; this is a player capability limit, not a descope of D-21's slider).
- Emit exactly one line with `jq -c -n --arg player … --arg label … --arg status … --arg title … --arg artist … --arg album … --arg art … --argjson position … --argjson length … --argjson volume … --argjson can_seek …` building the object. Using `--arg`/`--argjson` is the mitigation for T-08-07-01/06: jq performs the JSON escaping, so no quote, backslash, or angle bracket in a title can break out of the string.
- **Pango markup:** determine, against the installed eww, whether a `label`'s text is Pango-parsed by default. Launch a scratch window whose label text is a literal bold-tag string and observe whether it renders as markup or as literal characters (08-06's SUMMARY may already record this — check first). If — and only if — labels parse markup, add an escaping step in the jq pipeline mapping `&`→`&amp;`, `<`→`&lt;`, `>`→`&gt;` on `title`/`artist`/`album`/`label` before emission, and record the finding in the SUMMARY either way. Do not guess: a wrong guess here either lets a player inject markup, or renders `&amp;` visibly in every track title with an ampersand.
- `watch` — loop forever: run the `once` logic, print the JSON line only when it differs from the previously printed line, `sleep "$POLL_INTERVAL"`. This is the `deflisten` payload source. It must never exit on a transient playerctl failure; every external call inside the loop is guarded so a player appearing or vanishing mid-tick degrades to the empty payload rather than killing the listener.
- `position` — reserved subcommand printing only `{"position":N,"length":M}` for a future lower-cost seek poll; implement it (three lines, reuses the same field queries) but the widget tree does not need it if `watch` at 1 Hz proves smooth.
