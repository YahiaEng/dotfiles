| Boundary | Description |
|----------|-------------|
| cava stdout → applet | cava emits only a `;`-delimited numeric line to stdout; parsed as numbers, never as code. No untrusted string surface. |
| album art path → Gtk.Picture | The art path originates from the backend (`media.art`, resolved by `media-art-resolve.sh`); it is used as a file path for a picture, not passed to a shell. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-10-04-01 | Tampering | cava raw stdout parse | low | mitigate | Each frame is split on `;` and coerced with `Number()`; non-numeric tokens become `NaN` and only non-empty numeric arrays are applied. No cava output ever reaches a command. |
| T-10-04-02 | Information Disclosure | album-art file path | low | accept | The art path comes from the trusted backend resolver and is consumed as a `Gtk.Picture` source path only; the applet inherits the 08-07 no-metadata-to-command contract. |
| T-10-04-03 | Denial of Service | cava subprocess | low | accept | One cava subprocess per instance; a dead/absent cava simply yields no bars (empty underlay), never crashing the card. |
