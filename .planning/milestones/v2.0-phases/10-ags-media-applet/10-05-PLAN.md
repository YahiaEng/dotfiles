<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| matugen palette → ags.scss → applet CSS | matugen writes trusted, generated color vars to the state dir; the applet imports them as CSS values only, never as code. |
| theme post_hook → `ags request reload-css` | The post_hook sends the fixed literal `reload-css` verb to the AGS instance socket; no metadata is interpolated. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-05-01 | Tampering | reload-css requestHandler | low | mitigate | The handler matches only the exact literal `reload-css` and calls `app.apply_css` on the applet's own compiled stylesheet; no request value reaches a shell or command. |
| T-10-05-02 | Denial of Service | monitorFile watcher | low | accept | Watches a single state-dir file; a malformed/empty ags.scss would fail to compile and leave the previous CSS applied — no crash. matugen owns the file's content. |
</threat_model>
