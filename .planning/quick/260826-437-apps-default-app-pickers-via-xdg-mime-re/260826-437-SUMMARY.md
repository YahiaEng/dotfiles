# Quick Task 260826-437: Index-key split, real xdg-mime pickers, per-package updates Summary

**Split the settings module's index-key/display-label conflation into a seventh `indexLabel` property on all seven row primitives (closing the static-label bug for good), turned Apps' two dead InfoRows into real `xdg-mime`-backed File manager / Media playback pickers, and made each Updates grid cell a two-step-armed `paru -S --needed` per-package update.**

## Accomplishments

- `indexLabel` (defaulted to `label`, a live binding) on `InfoRow`, `NavRow`, `SelectRow`, `SliderRow`, `StepperRow`, `TextRow`, `ToggleRow` — every one of the ~176 existing rows keeps its exact current search-jump key with zero call-site edits; `RowIndex.qml` diff is zero bytes.
- `Pages.qml` now matches a search-jump target through `_rowKey()` (prefers `indexLabel`, falls back to `label`) instead of an exact `row.label` comparison.
- `settings-index-check` CHECK B rewritten: comment-stripped via a herestring (never a pipe — `X | grep -q` can exit 141 under `pipefail`), and now accepts `indexLabel: "X"` as well as `label: "X"`.
- `AllAppsPage.qml` shows each of the ~52 installed apps' own real name as its row title; the RowIndex jump key stays the single static string `"App"`.
- Apps page: **Media playback** and **File manager** are now real `SelectRow`s writing `xdg-mime default`, sourced from `gio mime` registrations intersected with a category predicate, current value read from `xdg-mime query default` (measured to disagree with `gio`'s own reported default on this host).
- Updates page: every `PackageCell` in the grid arms on first click and runs `paru -S --needed <name>` in the configured terminal on the second, via `Quickshell.execDetached`; a new `"Single-package updates"` `InfoRow` states the partial-upgrade risk in a searchable row.
