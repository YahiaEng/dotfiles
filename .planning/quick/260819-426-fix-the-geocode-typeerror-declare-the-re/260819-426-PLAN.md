# Quick Task 260819-426 — The geocode never ran

Operator: *"The country still reads cairo. Are you sure our geolocation lookup
method is accurate?"*

The lookup was accurate. It was never called.

## Investigation (systematic-debugging, four phases)

**Evidence gathered before any fix:**

| probe | result |
|---|---|
| `weather.json` coords | `31.20176, 29.91582` — Alexandria ✓ |
| `weather-cache.json` coords | same — the refetch happened ✓ |
| cached temperature | 25.6 °C — Alexandria's actual weather ✓ |
| cached `city` | `''` — **empty** ✗ |
| `payload.timezone` | `Africa/Cairo` |

The forecast had corrected itself. Only the city was missing, so the chain fell
to step 3 (timezone-derived) and printed "Cairo".

**Hypotheses tested and eliminated, in order:**
1. *Nominatim rejects the request* — no. curl with the component's exact URL and
   exact User-Agent returns HTTP 200 and `Alexandria`. (With **no** UA it returns
   403, so the header genuinely matters — but it is sent.)
2. *Qt does not put a custom User-Agent on the wire* — no. A local HTTP listener
   received `quickshell-dashboard-weather/1.0 (+https://github.com/YahiaEng/dotfiles)`
   verbatim from a QML XHR.
3. *Qt cannot reach Nominatim (TLS, etc.)* — no. A `qml6` harness got HTTP 200 and
   the Alexandria payload. `console.log` is invisible under `qml6` here, so the
   harness reported its result over a local socket instead.
4. *Wiring missing / wrong call sites* — no. Both call sites exist, brace depth
   confirms the resolver is a root-level member.

**Root cause, from `~/.cache/quickshell.log`:**

```
WeatherBackend.qml[313]: TypeError: Property '_resolveCityIfNeeded'
of object WeatherBackend_QMLTYPE_21 is not a function
```

18 occurrences. `_revalidateAgainstSettings()` is reached during construction —
the state `FileView`'s load path runs `loadCache()` → `_revalidateAgainstSettings()`
— while the resolver and the `GeocodeBackend` child were declared ~200 lines
below and did not yet exist on the object.

## Fix

Move the `GeocodeBackend` child and `_resolveCityIfNeeded()` above
`_revalidateAgainstSettings()`, with a comment recording why they must stay there.

## Verify

TypeError count after the reload must be 0 (was 18). qmllint, colour-lint,
motion-lint, quickshell-doctor, theme-doctor.
