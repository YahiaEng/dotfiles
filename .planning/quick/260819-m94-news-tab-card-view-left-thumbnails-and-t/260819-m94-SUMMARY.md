# Quick Task 260819-m94 — Summary

## What shipped

All three tasks landed, in the load-bearing order the plan specified:

1. **`NewsBackend.qml`** — `_childrenNamedNs()` (namespace-tolerant child
   lookup, correct whether `responseXML` reports a qualified or local tag
   name — unmeasured before writing, so written to be correct either way);
   `_imageOf()` (general preference order media:thumbnail → media:content →
   `enclosure[type^="image/"]` → none, no feed-specific branch anywhere,
   format-agnostic so both RSS and Atom call it); the image URL fence is the
   **THIRD** `https://` enforcement point (a bad image URL drops only the
   image, never the item); `image` wired through parse, the acceptance
   filter, and `loadCache()` revalidation (absent-key and empty-string
   converge on the same glyph-fallback render path — no migration, no cache
   invalidation); `view_mode` as a readonly computed `viewMode` property plus
   `setViewMode()`, a surgical read-modify-write that refuses to write if
   `sources` has no usable length, never a `writeAdapter()`-style whole-file
   republish (which would risk clobbering `sources`, confirmed not a native
   JS Array on this Qt build).
2. **`NewsPane.qml`** — a `viewToggleChip` beside the existing filter chip,
   mirroring its fill/radius/`Behavior on color` idiom, but a **toggle**, not
   a dropdown: one tap calls `newsBackend.setViewMode()` directly, no expand
   step. One delegate serves both modes — height is content-driven
   (`max(76, ~70) + 32` = 108px in cards, unchanged `implicitHeight + 16` in
   compact); the 76px `thumbSlot` mirrors `NotifCard.qml`'s `iconSlot`
   verbatim (always reserved, never blank, the card never changes width);
   the text column's `leftMargin` is conditional on `_cardMode`, so with
   `thumbSlot.width === 0` compact's left inset stays exactly
   `Design.spacingSm` — the 16px-shift trap the plan flagged is guarded.
   **The zero-request rule**: the `Image`'s `source` binding — never
   `visible` — gates loading, so compact issues zero image requests;
   `sourceSize` is pinned to `_thumbSize` so decode is bounded regardless of
   the source's real dimensions.
3. **`NotifCentre.qml` + `stow.sh` + the live host file** — `tabModel` gains
   a `glyph` role (`notifications` / `newspaper`); the `TabButton` delegate
   gains `required property string glyph`; `labelRow` gains a leading glyph
   `Text` that reuses the label's existing selected/unselected colour
   binding verbatim — no restructure, no third colour state. **The geometry
   guarantee holds**: the comment-stripped grep for every window-size token
   prints **0**, and `Design.qml` is untouched (the 76px thumb stayed
   module-local to `NewsPane.qml`, per the plan). **The glyph gate is
   poison-tested**: all four introduced ligatures (`notifications`,
   `newspaper`, `view_agenda`, `view_list`) shape to exactly 48.0px; the
   poison name `notification` (singular) shapes to 576.0px, proving the gate
   can fail. `stow.sh`'s seed and the live
   `~/.local/state/theme/news-sources.json` both carry BBC World, Ars
   Technica, LWN, Phoronix (all `https://`, no credentials) plus
   `"view_mode": "compact"`, and normalise byte-identical via `jq -S`.
