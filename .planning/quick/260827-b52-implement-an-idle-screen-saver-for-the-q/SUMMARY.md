# Quick task 260827-b52 — Aorus idle screen saver

Shipped in two stages. Stage 1 published a design study and ended at a
decision; stage 2 built the four styles the operator picked, under the
seven rulings the operator locked.

**Operator's brief, verbatim:** S1 Terminal Effects (default), S3 Palette
Aurora, S4 Constellation, S6 Edge Rail. Ladder 300 s with the dim; true
black backdrop with an annotated colour-lint exception; any input
dismisses; inhibit on MPRIS-playing and fullscreen; one surface per screen
animating independently; swappable branding plus the transcoder script;
styles behind a settings picker.

---

## The ruling everything rests on

Omarchy's screensaver spawns **one terminal window per monitor** running
`tte` over a text file. That mechanism is not ported. v4.0 spent six
phases deleting exactly that shape — waybar, swaync, swayosd,
walker/elephant, hyprlock — and `CLAUDE.md` states the rule outright.
`tte` is not packaged on Arch besides (measured). So the screensaver is a
Quickshell layer surface built like `modules/lock/`: N styles behind one
key, `Colours.qml`, `Motion.qml`, hot-reloading.

One consequence falls out for free. Omarchy sets screensaver 150 s / lock
**152** s because spawning a terminal resets the idle timer. Nothing is
spawned here, so the ladder needed no compensation.

## Five findings, four of them caught only by measurement

**1. Every static gate was green while the shell would not load at all.**
`colour-lint` 497/0, `motion-lint` 682/0, `qml-import-check` 167/0,
`settings-index-check` 182/0 — all passing across the same files that were
failing to load with *"Cannot assign to non-existent property families"*.
`font.families` is not a property of QML's font value type on Qt 6.11.2:
`QQuickFontValueType` in `/usr/lib/qt6/qml/QtQuick/plugins.qmltypes`
declares `family`, singular. The fix resolves the chain by hand against
`Qt.fontFamilies()`.

**Neither QML syntax tool works on this host, and both fail silently.**
`qmllint` returned rc=255 with zero output on a deliberately broken file
*and* on a good one; `qmlformat` returned rc=1 on a shipped, working file
and produced no stdout for anything. Both were caught by a positive
control. **The only instrument here that sees this class is the
hot-reload line in `~/.cache/quickshell.log`**, and it needs no restart.

**2. `qs ipc call <target> show` silently does nothing — and this repo
already knew.** The literal token `show` collides with the `ipc show`
subcommand in CLI11's parser, so the call prints the target's interface
listing and exits 0 without invoking anything. `bar-visibility.sh:254`
records the identical finding and the fix — `qs ipc call -- <target> show`.
I reproduced it before finding that comment. The hypridle chain uses `--`.

**3. The surface dismissed itself the instant it appeared, and my own
comment asserted it could not.** The file claimed `positionChanged` "only
fires on real movement, so a pointer that merely happens to sit under the
surface when it appears does not dismiss it instantly." False: mapping a
full-output layer surface under a stationary cursor delivers a position
event immediately. Measured — `show()` set `active = true`, two seconds
later `isActive` read false with zero surfaces. Fixed with two independent
guards: an arming delay of `Motion.standardDuration`, and an origin point
so only movement beyond `Design.spacingSm` counts. Keyboard, click and
wheel are ungated.

**4. An unquoted heredoc executed my own comment.** `idle-overrides.sh`'s
`_render` uses `<<CONFEOF`, not `<<'CONFEOF'`, so bash expands the body —
and backticks in a comment are **command substitution at render time**.
The script hung with a zero-byte `.conf.tmp` while bash sat blocked on a
real `qs ipc call screensaver show` it had forked out of my prose. A
second block would have executed `brightnessctl`. Every backtick in that
heredoc is now escaped, as the pre-existing ones already were, with a
warning at the top of the block.

**5. A false pass I nearly shipped.** To exercise the three non-default
styles I wrote `screensaver.style` into `prefs.json` and forced a config
reload. All three reported `raised=true, surfaces=1, errors=0` — and all
three were **still running `terminal`**, because `Prefs` keeps its state
in memory across reloads (`watchChanges: false`). The tell was `status`
printing `terminal` under all three. Re-verified by pinning the style in
`Screensaver.qml` for one reload each: aurora / constellation / rail /
terminal each resolved to **its own name**, raised a real surface, and
produced zero new errors. The pin is removed; `prefs.json` is restored.

## Verified live, without a restart

- `show` → `isActive=true`, one layer surface; persists; `hide` → `false`, zero surfaces
- The **exact rendered hypridle chains** run end to end: `on-timeout` raises it, `on-resume` tears it down
- All four styles instantiate and raise a surface with zero errors
- The media relay is live — `status` reports no `DEGRADED`, which is a
  distinct arm added precisely because a severed relay and "nothing
  playing" otherwise print the same string
- `exclusiveZone: -1` confirmed incidentally: the surface spans `0 0`, not
  `0 6`, against a reserved zone of `[0,6,50,6]`

Two things measured that were **not** my change: the monitor read
`FALLBACK 1920x1080` during testing (display asleep, not a geometry bug),
and `brightnessctl -s set 30%` exits 0 on this backlight-less host by
falling through to a `leds` device — so the `&&` chain never
short-circuits before reaching the saver. It is currently dimming the
ethernet port's LAN LED; pre-existing, harmless, noted so it is not
re-derived.
