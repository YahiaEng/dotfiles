## Item 1 — `quickshell-doctor --self-test` reads 58/1 and that 1 is mislabelled

### What was measured (not assumed)

Ran `keybind-doctor tests/quickshell-fixtures/compliant-overview-keybinds.lua
quickshell/.config/quickshell/shortcuts.json` directly. Result: **12 passed, 1 failed.**

- The chord-collision check **PASSES** — `(found: 0)`.
- The real failure is `declared-vs-registered: all 5 declared binds appear in
  hyprctl binds (missing: 1)`, naming
  `compliant-overview-keybinds.lua:14 ... hl.dsp.global("quickshell:overview")`.

So STATE.md's description is correct: the self-test asserts on keybind-doctor's
**whole exit code** while printing as a chord-collision verdict.

### The larger finding STATE.md did NOT have

The drift is **not confined to the fixture**. The shipped manifest
`quickshell/.config/quickshell/shortcuts.json` still declares:

```json
{ "appid": "quickshell", "name": "overview", "chord": { "mods": "SUPER", "key": "O" } }
```

while `hypr/.config/hypr/config/keybinds.lua:265` binds:

```lua
hl.bind(mainMod .. " + Tab", hl.dsp.global("quickshell:overview"))
```

`keybind-doctor`'s collision check (keybind-doctor:605-626) walks the **manifest**
chords and looks for declared binds claiming the same `(modmask, key, release)`
tuple. Nothing declares `Super+O` any more — `hyprctl binds` has **zero** `key: O`
entries — so `COLLISION_COUNT` is 0 **vacuously**. The check has been blind to the
overview chord since the bind moved: if any bind now claimed `Super+Tab`, the gate
would not notice.

`GlobalShortcut` (shell.qml:1932-1937) registers by `appid`/`name` only and never
reads `chord`, so the manifest's `chord` field is purely keybind-doctor's
cross-check contract (as keybinds.lua:230 says). Re-pointing it is safe at runtime
and is what restores the gate's coverage.

A full cross-check of all 13 manifest entries against every
`hl.dsp.global(...)` bind in keybinds.lua found **exactly one** real drift
(overview). Two other rows flagged by a first, buggy parser were false: `launcher`
legitimately carries a second chord (`Super+R`, keybinds.lua:98), and
`launcher-menu` declares its release edge via a `{ release = true }` options table
(keybinds.lua:99), which the first parser did not read.
