## Plan decisions (D-05/D-06 discretion + RESEARCH.md Open Questions, resolved)

- **PD-01 — Prefs path and schema.** `~/.local/state/quickshell/prefs.json` (mode `drwxr-xr-x`, already holds `notifications.json` and `bar-orientation`; `~/.local/state/theme/` is `drwx------` and is the theme engine's render-target dir — not there). Flat top-level namespaces, `"version": 1` from day one (`NotifServer` had to retrofit a migration for a file that shipped without one). Defaults live in QML as `or`-fallbacks; the file is allowed to be absent, and is NOT seeded by `stow.sh` (following `notifications.json`'s absent-is-normal precedent, so `stow-link-check` needs no change).
- **PD-02 — Ten nav pages, not eight.** The operator's own rendered layout block lists ten entries. "Roughly eight" in the prose is the approximation; the block is the spec. Ten it is.
- **PD-03 — Deep-link resolution (RESEARCH.md Open Question 1).** `openSettingsPage(name)` gains a two-stage resolver: exact `slug` match FIRST (new, precise: `bar`, `notifications`, `session`, …), then `category` **first-match-wins by index** (legacy: `appearance`→0, `connectivity`→3, `display`→5, `shell`→7). Both rules documented in `PageRegistry.qml`'s header, and a startup assertion warns if any of the four legacy keys stops resolving. There are today **zero** external callers of these keys — `grep` over `quickshell/`, `hypr/`, `walker/` finds only the IPC verb itself — so first-match-wins introduces no regression.
- **PD-04 — Bar capsule prefs consumption site (RESEARCH.md Open Question 2).** `BarEntryModel.capsulesForZone()` — the single resolution function every zone renders through. Filtering there covers all zones and both orientations in one edit. `requiresBackend()` and the `requiresResources`/`requiresMedia`/`requiresAudio` aggregates are deliberately NOT filtered: hiding a capsule must never stop a backend the dashboard also reads.
- **PD-05 — record-toggle.sh defaults scope (RESEARCH.md Open Question 3).** Bounded to the three values that are already literals in one `gpu-screen-recorder` invocation plus the audio mode that is currently re-asked interactively on every recording: **fps**, **codec**, **audio default**. Container, capture-target selection, the CPU-fallback flag and the notification/GIF pipeline are untouched. This is a bounded flag-plumbing change, not the script redesign the research warned it could become.
- **PD-06 — Inline pickers.** Font, icon theme and fastfetch logo all become inline `SelectRow`s backed by a new non-interactive `--list`/`--set` pair on their own picker script (the same shape four times). **Wallpaper is escalated to the operator as a decision checkpoint (Task 14)** — a text dropdown over a wallpaper directory is a worse control than the existing image-preview picker, and an inline thumbnail grid is a new surface. The planner does not get to decide that trade silently.
- **PD-07 — `InfoRow` is focusable.** It declares `focusable: true` + `rowFocused` like every other row primitive, with no activation behaviour. This keeps `settings-index-check`'s denominator uniform across all five primitives, and makes explanatory rows reachable by search and by keyboard.
- **PD-08 — Search matching is substring, case-insensitive**, over `label + " " + section + " " + keywords`. Not fuzzy: at ~75 rows a wrong fuzzy hit at the top of the list is worse than a missing substring hit, and the `keywords` field is where synonyms go.
</decision_ids>

<live_pass_lessons>
Six rules from 260820-sqd's nine post-plan fix waves. Every one of them bites this task. They are procedural obligations on the executor, not background reading.

1. **`colour-lint` (GATE-04) cannot see default-styled QQC2 popups.** The gate stayed green while every dropdown in the window shipped the system palette. The defect lives in Qt's installed `Menu.qml`/`MenuItem.qml` (`color: control.palette.window`), in a file colour-lint does not scan. **A green run is not evidence.** Every new `SelectRow`/`Menu`/`ComboBox`/`TextField`/`Popup` makes the four moves in `<qqc2_contract>` below.
2. **The restart-then-edit deployment trap.** A quickshell restarted BEFORE the final edit serves stale compiled pages, because `PageCompRegistry`'s per-page indirection keeps handing back the old `Component`. **Every verification round in this plan is `edit → commit → systemctl --user restart quickshell.service → wait → open → verify`, in that order, never reordered.** Hot-reload is not trustworthy for anything under `modules/settings/pages/`.
3. **Confirm WHICH element a visual report names, with a screenshot, BEFORE fixing.** Three of nine waves correctly fixed the dropdown popup while the operator meant the page rows.
4. **Verify visuals by pixel-sampling, never by role name.** Four controls shipped `surfaceVariant`-on-`surfaceVariant` — invisible by construction, with entirely correct-looking role names. `grim -g <region>` capture of the settings toplevel is PROVEN SAFE on this host (13+ captures). Full-screen `grim` is NOT — it SIGSEGVs the compositor into safe mode.
5. **Drive the real UI path with the operator's real values.** A test that injects below the UI layer verifies plumbing, not product.
6. **When agent trials pass while the operator fails, STOP and instrument.** Both endgame diagnoses last time came from the operator's own trace, not from any synthetic trial. Do not spend a third round guessing.

**Two additional standing prohibitions for this task:**
- **Never spawn a `qml6` probe script.** Each opens a real window; a loop of them takes the session down. Use Python, `qs ipc call`, static gates, `hyprctl -j`, or `~/.cache/quickshell.log`.
- **Every `Process.command` is a fixed-argv array.** Device names from `hyprctl -j` and node names from PipeWire are not this repo's own text.
</live_pass_lessons>

<qqc2_contract>
The four moves every new QQC2 control MUST make, copied from the already-fixed `SelectRow.qml:229-302`. Referenced by ID from the tasks below; do not re-derive.

- **Q-1** — Override `Menu.background` / `Popup.background` with an explicit `Rectangle { color: Colours.surfaceVariant; border.width: 1; border.color: Colours.outline; radius: 12 }`. Never inherit.
