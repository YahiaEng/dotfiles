<objective>
Replace the fzf-in-kitty icon-theme and font pickers with QML surfaces.

Two surfaces, one backend:
- **Specimen** — launcher word routes `icon` and `font`, on the `WallpaperMode.qml`
  / `PkgMode.qml` pattern. The typed path.
- **Atelier** — one `FloatingWindow` with `Icons | Fonts | Catalogue` tabs, on the
  `Workbench.qml` pattern. The keybind path, and the only home for the catalogue.

Purpose: the `--list` / `--set` contract already exists and is proven; what has no
QML equivalent is the montage icon grid and the live font specimen. That is what
is being replaced. The scripts keep their machine-facing tail and lose their
interactive half.

Output: a new `modules/appearance/` module, two new launcher modes, keybind
package B, two stripped scripts, two deleted window rules, and the standing
v5.0 ICON-BROWSE candidate struck.

**Decision IDs.** CONTEXT.md numbers its locked decisions `D1`-`D4`; this plan
cites them as **D-01 = D1** (build both Specimen and Atelier), **D-02 = D2**
(keybind package B), **D-03 = D3** (strip the interactive half of both scripts),
**D-04 = D4** (catalogue install is in scope now). All four are LOCKED — this
plan implements them, it does not reopen them.

**One design call the executor should surface rather than bury.** D-04 asks for
"a real progress log". A package install needs root (repo) or a TTY for build
prompts (AUR), and the sibling `PackagesBackend.qml` states its posture in its
own header: *"There is no pkexec verb and no polkit action for packages."*
Introducing one here would be a new privilege surface contradicting the shipped
precedent. So Task 3 streams a real, live log for everything QML can observe —
enumeration, validation, the before/after theme-directory diff, the resolved
theme name — and hands the privileged install itself to a terminal exactly the
way `PackagesBackend.runTransaction` does. The log is real; it is not a fake
progress bar over a hidden `sudo`.
</objective>

<measurements_that_shape_the_build>
Carried verbatim from CONTEXT.md. These are measured facts, not preferences.

**M1 — three of eight icon themes render an identical grid at 48px.** `Papirus`,
`Papirus-Dark`, `Papirus-Light` are byte-identical (same MD5) at every 48x48 icon
probed. The variants override only 16/18/22/24px glyphs.
→ **The icon grid previews at 22px, never 48.**

**M2 — 13 of 39 font entries are metrically identical twins.** 39 names =
13 families x {`Nerd Font`, `Nerd Font Mono`, `Nerd Font Propo`}. `Nerd Font` and
`Nerd Font Mono` are identical on every probed advance width; only `Propo`
differs, and only on icon glyphs. fontconfig agrees (`Propo` reports no
`spacing`, the other two report `100`).
→ **Collapse the duplicate cut. Offer 13 families x 2 spacing behaviours.**

**M3 — no icon name exists in all eight themes.** Adwaita ships no
`utilities-terminal` / `text-editor` / `system-file-manager`; AdwaitaLegacy is
PNG-only; breeze has no `firefox` / `text-editor`.
→ **Every grid cell needs a fallback chain, and a miss is shown, not hidden.**
</measurements_that_shape_the_build>

<traps_designed_around>
Every one of these has already cost this project a session. They are constraints
on the tasks below, not background reading.

| Trap | Consequence if ignored | Design response |
|---|---|---|
| `colour-lint` (GATE-04) rejects hardcoded colours in QML | gate red-lights | read every colour from `Colours.qml`, every duration/curve from `Motion.qml` |
| A `Colours` role is a **string**, not a `color` — `.r`/`.g`/`.b` are `undefined` and `Qt.rgba()` of them renders **pure black** | invisible black panel | assign through a `property color` first (Workbench.qml's `surfaceBase`), or use `Qt.alpha()` / `Qt.tint()` |
| `follow_mouse=1` makes Qt's `Window.active` a **hover** signal | window dismisses when the mouse leaves | `HyprlandFocusGrab` for click-outside, per `Workbench.qml:361-364` |
| A focus grab is **exclusive** — another process's dialog is input-dead while held | the install terminal cannot be clicked | release the grab (close the window) *before* launching the terminal, per `Workbench.qml`'s `onTransactionLaunched` |
| A component-scoped `Process` dies with its `LazyLoader` | apply killed mid-flight | long-running work lives on the **singleton** backend; anything that must outlive the shell uses `Quickshell.execDetached` |
| Every module dir has a `qmldir`; an undeclared type is unresolvable **with no load error** | reads `undefined` forever | declare each new type in the SAME commit that creates it |
| `MenuTree.qml` leaf labels carry invisible Nerd Font private-use glyphs (U+F021 family) | an edit matched on the visible label silently no-ops | anchor edits on the machine-written `command:` field and **read the file back** after writing |
| A Hyprland window rule silently overrides QML geometry | Atelier renders at someone else's size | grep `windowrules.lua` for the new toplevel's class/namespace before sizing it |
| `qmllint` / `qmlformat` are **blind here** (rc=0 on a truncated file) | a broken file passes every gate | the ONLY QML load-error signal is `~/.cache/quickshell.log`; capture its byte length before an edit and read only what was appended |
| A grep gate matches its **own** prose | gate can never go green | after removing a token from a script, grep for it again — a leftover changelog comment is a hit |
| Declare-before-use: a later-declared QML member throws "is not a function" at construction time | plausible wrong answer via a fallback chain | declare `function`s and `property`s above anything that reads them |
| **Forbidden from an agent shell:** restarting quickshell, `quickshell-doctor`, `qml6` probes, `grim` screenshots on this host | kills the session / crashes the compositor | verification is static gates + log reads only; live checks go to the operator (see `<operator_checklist>`) |
</traps_designed_around>
