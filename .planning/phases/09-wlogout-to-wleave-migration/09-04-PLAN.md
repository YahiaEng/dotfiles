## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| overlay layer with exclusive keyboard → the session | A surface that cannot be dismissed holds the session's keyboard; the dismissal paths are the control |
| power action → session/system state | Logout, shutdown and reboot cross an irreversible session boundary, so the order in which they are tested is itself a safety property |
