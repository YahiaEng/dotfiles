## Ordering Constraints (load-bearing)

1. **Tracer first.** 18-01 proves `exclusiveZone > 0` end-to-end on the live host before any capsule, popout or retirement work is planned. Everything expands from that proven surface.
2. **GATE-01 before deletion.** 18-02's enumeration is read off the **live** waybar config while it still exists (wave 1), eight waves before 18-20 removes it.
3. **GATE-02 before deletion.** 18-19 is a blocking human gate in wave 9; 18-20's deletion commit cannot run until it passes. RETIRE-02 therefore cannot be planned into an early wave.
4. **RETIRE-01 twice.** The checklist script is built in 18-06 (wave 2) and run against waybar there for the pre-deletion baseline; 18-20 runs it again after deletion. Both must report zero blocking-tier hits.
5. **GATE-03 inverts, never extends.** `_qsd_check_reserved_array_manifest_coverage` asserts an invariant the bar breaks by design — 18-17 rewrites the assertion rather than layering a contradictory second check beside it.
6. **GATE-04 is minted before the bar's capsules land** (wave 1), so no bar surface is ever born outside the hex-literal lint.

## Named Hazards Carried Into Every Plan

- First surface in this repo with `exclusiveZone > 0`; first with **no dismissed state**, so it inherits none of the zero-idle discipline every prior LazyLoader-summoned surface relies on; and it shares a process with the Phase 19 notification server. 18-07's restart unit and 18-18's soak are the mitigations.
- The bar deliberately goes **denser** than end-4/Caelestia. Do not simplify toward the reference shells — that reading is wrong for this phase.
- `Colours.qml`'s own 19 `"#FF00FF"` fallback defaults must not false-positive GATE-04 (18-03 scopes the regex to `color:` context, mirroring `motion-lint`'s precedent).
- LEDGER-03 uses `QSG_RENDER_TIMING=1`, never Hyprland's debug overlay.
- D-18-27's *conclusion* stands, but its recorded rationale ("Quickshell cannot detect idle") is factually wrong — `Quickshell.Wayland._IdleNotify.IdleMonitor` exists. Do not repeat the false claim in any plan.
