<objective>
Deliver GATE-03 and QBAR-12 by making `quickshell-doctor` tell the truth about a desktop that
now reserves screen space.

Two of this file's invariants were falsified by the bar shipping in wave 1, and neither is a bug
to fix — both are assertions that must be **rewritten**:

1. **"Quickshell claims no reserved screen space."** Stated in the file's own header and asserted
   by check 5. The bar is the first surface in this repo with `exclusiveZone > 0` and it is
   permanent. The replacement is QBAR-12's literal text: the bar's own reservation **exists**,
   is attributable to the bar alone, and is **byte-identical across `hyprctl reload` and a QML
   hot reload**.
2. **"Every `quickshell-*` layer namespace sits at the overlay level."** Asserted by check 4.
   `Bar.qml` sits on the top level by design — always-on chrome belongs below transient dialogs
   and below a session-lock surface. The replacement is a per-surface expected level read from a
   registry.

And one thing this phase created that nothing yet watches: **frames**. `PanelDialog.qml`'s header
forbids bespoke `PanelWindow`s; D-18-15 knowingly added a second one and paid for the exception
with a promise that GATE-03 would register it. 18-16 added a third. 18-11 has a fourth waiting on
an open decision. This plan builds the registry that closure runs through, in both directions, so
the fifth cannot ship unregistered.

## What "invert, do not extend" means concretely here

Layering a second check beside a false one leaves a file that argues with itself, and a reader who
believes whichever line they hit first. So: the header line is rewritten, check 5's label is
rewritten to what its mechanism actually proves (a delta assertion — summoning a manifest surface
must not change the reservation — which is still true and still valuable), check 4 consults the
registry, and `_qsd_check_reserved_array_manifest_coverage` is rewritten in place under a new name
carrying the new assertion. Afterwards, **no line of live code claims Quickshell reserves nothing.**

The one thing that is preserved rather than replaced is the manifest token-allowlist guard that
function actually held. That guard is real coverage — it is what stops a future manifest entry from
silently falling out of check 5's dispatch loop — and it is folded into the new check's report as a
named sub-assertion rather than deleted along with the framing that surrounded it. Folding several
sub-assertions into one reported line is this file's own convention, not an invention here.

## A correction to two upstream artifacts, made once and not repeated

`18-RESEARCH.md` Pitfall 6 and `18-PATTERNS.md` both send the reader to
`_qsd_check_reserved_array_manifest_coverage` at line 966 for the "stays unclaimed" assertion. It
is not there. That function asserts manifest token safety. The falsified claim lives in the file
header's third line and in the inline check at lines 1517-1552. Both artifacts' **conclusion** is
correct and this plan executes it; only the address is wrong. Recorded here so the executor does
not read line 966, find something else, and assume the plan is confused.

## The hazard this plan owns, and does not trip over

`hyprctl reload` and this host's layer rules are a known-expensive interaction: on this Lua-parser
build a reload does not apply `hl.layer_rule` changes at all, silently, with `hyprctl configerrors`
clean — and the resulting missing blur is visually indistinguishable from an alpha value sitting
under the family's `ignore_alpha` floor. A previous render gate burned five rounds tuning numbers
against a rule set the compositor had never read.

QBAR-12 names `hyprctl reload` explicitly, so the reload must be exercised. This plan therefore
owns the restore, and takes the honest route rather than the cheap one:

- The reload half is **opt-in** (`--with-compositor-reload`), so nobody's casual `quickshell-doctor`
  run silently costs them their blur. This is the first opt-in flag in a file whose four existing
  flags are all opt-outs — named here as a deliberate inversion, not an oversight, because the
  default for a hazardous mutation must be "off".
- The restore **re-applies the `quickshell` layer rules from `windowrules.lua` in that file's own
  declaration order** through `hyprctl eval`, then restarts the shell so the rules bind at surface
  map time, from a trap installed before the reload runs.
- The restore is **not** claimed as mechanically verified. Layer-rule effects carry no `hyprctl`
  projection on this build, so there is nothing to read back. Task 2 ends with a screenshot and a
  human looking at it — the specific discipline this exact failure earned.

## Explicitly NOT in this plan

- **No new QML.** Every surface this plan registers already exists; this plan adds a checker, not
  a frame.
- **No change to `bar-visibility.sh`, to its intent files, or to the exclusive-zone policy.** All
  three are 18-15's. This plan calls exactly two of the owner's read/verb pairs and restores state.
- **No new IPC verb.** 18-15's `bar` handler is called for nothing here; the reservation is
  measured from the compositor, not asked of the shell.
- **No fold into `theme-doctor`.** D-18-35's fold is `retirement-check`'s (18-06);
  `quickshell-doctor` has always stood on its own and continues to.
- **No `hyprctl eval` with the Hyprland debug overlay, ever.** LEDGER-03 uses render timing; that
  instrument froze this exact host hard enough to require a physical restart.
- **No UI work of any kind.** `18-UI-SPEC.md`'s `## UI Considerations` rows are scoped to the seven
  rendered surfaces; this plan modifies a bash checker and ships no pixel. Stated as an explicit
  scope fact rather than left as a silent omission.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Invocation arguments and environment → `quickshell-doctor` | The flags and the ten-going-on-fourteen `QSD_FIXTURE_*` seam variables. | `windowrules.lua` on disk → `hyprctl eval` | The one code-execution sink this plan introduces. Text read from a repo file is replayed as a Lua expression into the running compositor. | `quickshell-doctor` → `bar-visibility.sh` → the bar's rendered state | The check borrows the owner's state machine to take a measurement. One-directional: the doctor calls two of the owner's verbs and reads its status; it writes no intent file and the owner remains the only writer. |
| `quickshell-doctor` → the compositor and the user's shell process | The check reloads the compositor and restarts the shell on its opt-in path. This is the widest blast radius any check in this file has ever had. |
| The check's own report → every downstream reader | A gate's output is a trust signal. A line that reads as coverage while proving nothing is a failure of this boundary, and it is the failure this plan exists to correct in the first place. |

No network listener, no credential handling, no privilege boundary, no peer-supplied input and no
untrusted file parsing exists anywhere in this plan's scope. The only inputs are this repo's own
files, this host's own compositor output, and the invoking user's own arguments.

All six are answerable from the locked artifacts and the shipped source, so all six are resolved
here by hand and authored as plain-string acceptance criteria in `must_haves.truths`. Nothing was
auto-dismissed, nothing was silently dropped, and nothing was classified `unclassifiable`.

| Requirement | Probe category | Resolution, and where it landed |
|-------------|----------------|----------------------------------|
| QBAR-12 | adjacency — "when two things are exactly equal or just touch, do they merge, collide, or separate?" | They **sum**. waybar and the bar both anchor the same edge at this wave, so the raw reservation on that axis is both bars added together and no reading of it attributes anything to the bar. | QBAR-12 | empty — "what is the result for empty, single-element, or null input?" | A monitor reserving nothing reads four zeros, which is a real value and not a missing reading. | QBAR-12 | ordering — "when elements compare equal, is output order specified and stable?" | Genuinely load-bearing and the most valuable of the six. `hyprctl monitors -j` emits monitors in enumeration order, so a positional byte-comparison reports drift when a monitor is hotplugged between two readings and nothing has actually moved. | GATE-03 | adjacency | `quickshell-bar` is a strict prefix of `quickshell-bar-hotzone`, so a prefix test matches both and double-counts one surface, quietly breaking the permanent frame's cardinality assertion.   the replay.
