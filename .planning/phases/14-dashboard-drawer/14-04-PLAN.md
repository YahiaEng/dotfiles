## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Drawer QML → shell command execution | A pointer press inside the drawer causes a child process to run with the user's own privileges; whatever ends up in the command array is what runs |
| swaync daemon stdout → the drawer's DND state | A long-lived third-party process streams JSON into the QML engine's parser, one line at a time, for as long as the drawer is open |
| Hand-editable state files (`~/.cache/gaming-mode`, `~/.local/state/theme/mode`, `~/.local/state/theme/motion-scale`) → rendered toggle state | Plain-text files any local process can write decide what the grid claims the system is doing |
| Drawer surface lifetime → child-process lifetime | A surface destroyed on dismiss owns processes and timers that must die with it, several times per session |
