  <action>
    Build D-21's cascade as one reusable runner plus one ordered list per tab. No tab
    file gets animation code of its own, and no timing value is written anywhere but
    the token aliases.

    **The runner — a new type `Cascade` at `modules/dashboard/Cascade.qml`.** It is
    non-visual: derive it from `QtObject` so it can never contribute geometry to a
    frame D-04 fixes. Its API is five names and two functions:

    - `bands` — an ordered list of items, read order first to last, supplied by
      whichever tab is showing.
    - `armed` — true when a cascade is owed. The drawer root sets it; the runner
      consumes it.
