# Phase 14 — UI Design Contract

> Visual and interaction contract for the Dashboard Drawer, the first real
> content-bearing QML surface. Generated by gsd-ui-researcher, verified by
> gsd-ui-checker. This is a Quickshell/QML desktop-shell surface, not a web
> app — there is no shadcn/Tailwind/npm stack in this repo. The design
> system instead is this repo's own token pipeline: `Colours.qml` /
> `Motion.qml` singletons reading matugen-rendered
> `~/.local/state/theme/{palette,motion}.json`. This contract maps the
> template's web-shaped sections onto that pipeline's actual vocabulary and
> restates DASH-relevant decisions already locked in `14-CONTEXT.md` so the
> planner/executor/checker have one place to check against — it does not
> re-decide anything CONTEXT.md already settled.

## Spacing Scale

Declared values (must be multiples of 4) — **this is the scale already live in this repo's QML** (`Probe.qml`'s `spacingXs`..`spacingXl` constants), not a new proposal. D-06 locks "MD3 comfortable spacing uniformly (8dp grid)" for this phase.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, chip internal padding, dial tick spacing |
| sm | 8px | Compact element spacing (tab icon/label gap, toggle chip internal gap) |
| md | 16px | Default element spacing (card gaps — D-06's "~16px card gaps") |
| lg | 24px | Panel padding (D-06's "~24px panel padding"), section separation |
| xl | 32px | Reserved — not expected to be exercised inside the drawer's compact ~850×860px frame (D-02); available if a tab's outer layout needs it |
| 2xl | 48px | Not expected to be used — the drawer's fixed compact frame (D-02/D-04) has no room for a break this large |
| 3xl | 64px | Not expected to be used |

Exceptions:
- **D-05 (no vertical scrolling, ~10-15% vertical slack budget)** governs every tab's total content height — this is a layout constraint layered on top of the spacing scale, not a spacing-token exception itself.
- **Circular dial component (Performance tab + Dashboard's resources strip, D-36/D-39)** is custom `QtQuick.Shapes`/`Canvas` geometry — its arc radius/stroke-width are dial-specific render-gate discretion (per 14-RESEARCH.md's "Don't Hand-Roll" table), not spacing-scale values; do not force dial geometry onto the 4px grid.
- **Fixed 8-column hour strip (Weather tab, D-37)** — column width is derived from `(drawerWidth − 2×lg-padding) / 8`, a computed value, not a fixed spacing token; document the formula in the plan rather than hardcoding a pixel width.

## Typography

No project-wide 3-4-size type scale exists yet in this repo's QML (Probe.qml uses ad hoc `font.pixelSize` values: 22, 18, 14, 12, per the file's own header comment acknowledging this as unresolved debt). Phase 14 is the first content-bearing surface, so this contract **declares the scale now** rather than perpetuating ad hoc sizing. Executor should introduce these as named constants (e.g. on the drawer's root item, mirroring `Probe.qml`'s `spacingXs..Xl` pattern) rather than inlining `font.pixelSize` literals repeatedly.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Display | 32px | `Font.Medium` (500) | 1.2 — clock/date hero (D-38), weather current-hero temperature (D-37) |
| Heading | 20px | `Font.DemiBold` (600) | 1.2 — tab content section headers, dial center values |
| Body | 16px | `Font.Normal` (400) | 1.5 — track title/artist, forecast rows, calendar cell numbers |
| Label | 12px | `Font.Normal` (400) | 1.5 — tab bar labels, chip text, timestamps/badges ("updated Nh ago", D-33), dial captions |

Weights: exactly 2 declared as the template requires (`Font.Normal` 400, `Font.DemiBold` 600) plus `Font.Medium` (500) reserved for the single Display role only — this is a 3-weight system, one weight beyond the template's 2-weight default, justified because MD3's own type scale (which D-06/D-24/D-28 anchor to throughout CONTEXT.md) distinguishes a hero/display weight from body emphasis. If the render gate finds `Font.Medium` visually redundant against `DemiBold` at this size, collapse to 2 weights (Normal + DemiBold) as a render-gate-time simplification — this is documented headroom, not a mandate to use all three everywhere.

**Font-axis guard (ties to D-05):** the entire spec above must survive font substitution/scaling — D-05's "no vertical scrolling, ~10-15% slack" budget is explicitly judged "across themes/fonts" at the render gate, so no tab's layout may assume these exact pixel sizes are the ceiling.

## Color

This repo's color system is **19 Material You semantic roles** (`Colours.primary`, `Colours.onPrimary`, `Colours.surface`, etc. — see `Colours.qml`'s `roles` list), not a fixed hex palette — the actual values are matugen-rendered per-theme/per-wallpaper and unknown at spec-writing time. This section maps the template's 60/30/10 framing onto that role system rather than inventing hex codes that would immediately go stale.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `Colours.surface` / `Colours.onSurface` | Drawer background (translucent per D-07's house treatment — `blur = true` + `ignore_alpha`), tab content default text |
| Secondary (30%) | `Colours.surfaceVariant` / `Colours.onSurfaceVariant` | Cards/widget containers (resource dial backgrounds, media widget card, calendar grid), inactive tab bar items, un-lit toggle chips |
| Accent (10%) | `Colours.primary` / `Colours.onPrimary` | **Reserved for:** the active tab indicator (D-16), the lit/filled state of the 3 mirrored toggle chips (D-25 — "active = filled with primary"), the active segment of the motion-scale row (D-24), the play/pause button's pressed/active state (D-40), the calendar's "today" highlight (D-34), the pending-pulse affordance (D-22) |
| Destructive | `Colours.error` / `Colours.onError` | Reserved for: genuine failure states only — e.g. a fetch that fails outright past D-33's calm-stale grace path (not the routine stale badge itself, which uses a "warning tone" at the ~6h threshold per D-33, distinct from a hard error); no destructive *actions* exist in this phase's scope (no delete/remove affordance anywhere in DASH-01..08) |

Accent reserved for: active tab indicator, lit toggle chips (Gaming/DND/Dark when ON), active motion-scale segment, play/pause active/pressed state, calendar "today" cell, pending-pulse animation — **never** applied as a general interactive-element default (e.g. all buttons are NOT tinted primary; only the ones enumerated above and in D-25/D-26).

**Second semantic tone (D-33's warning badge):** the "updated Nh ago" staleness badge needs a distinct warning tone at the ~6h threshold, separate from `error`. `Colours.qml`'s 19-role list has no dedicated "warning" role today — **planner discretion**: either add a warning role to the palette pipeline (a Phase-12-owned pipeline change, likely out of this phase's scope) or reuse `Colours.tertiary`/`onTertiary` (already present, unused by the drawer elsewhere) as the pragmatic no-new-role choice. Recommend the latter to avoid touching Phase 12's closed pipeline.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | No traditional "primary CTA" exists — the drawer is a glanceable dashboard, not a form. The closest analogs are per-widget deep-links: Dashboard tab's compact media widget and resources strip both act as **tap targets that jump to their full tab** (D-40's "clicking anywhere else deep-links to the Media tab"; D-39's "clicking jumps to the Performance tab") — no separate label needed, the whole widget is the affordance |
| Empty state heading | Not applicable as a heading — D-41 mandates **in-place placeholders**, not empty-state screens: "quiet Material Symbol + one line" |
| Empty state body | Per-widget, one line each, matching D-41's "quiet" register: Media tab with no active player → *"Nothing playing"* (Material Symbol: `music_off` or similar outlined icon); Weather tab with no cache ever fetched → *"Weather unavailable"* (D-33's "designed placeholder inside the intact frame ONLY when no cache has ever existed"); Performance tab battery dial on this hardware (no battery present) → *"No battery"* (this is the tested case per 14-RESEARCH.md Pitfall 3 — the ONLY locally-verifiable empty state for that widget); Calendar/resources/toggle-grid have no empty state (D-05 audit found nothing unbounded — these always render) |
| Error state | Weather stale-but-not-empty (D-33): *"Updated {N}h ago"* badge, calm tone until ~6h then a warning tone shift (color only — copy stays identical, no alarming language per D-33's "calm stale-as-normal" instruction). No other genuine error-copy surface exists in this phase — media/toggle/performance all read local scripts/kernel files that either return data or fall through to D-41's quiet empty placeholder, never a scary error string |
| Destructive confirmation | **None in this phase.** No destructive action exists in DASH-01..08 (confirmed: no delete/remove/reset affordance in any of the 43 decisions). The three quick-toggle chips and motion-scale row are reversible one-press state flips, not destructive actions — D-22's pending-pulse (not a confirmation dialog) is the correct affordance for their in-flight state |

## Appendix: Locked Interaction Contract (from 14-CONTEXT.md, restated for the checker/executor)

These are not re-decided here — they are the geometry/motion/lifecycle facts a visual checker needs without re-reading the full 43-decision CONTEXT.md:

- **Placement:** top drop-down, horizontally centered, flush to top edge, bottom corners rounded only (D-01/D-03)
- **Size:** ~40% width (~850px) × ~60% height (~860px) on the 2160×1440 primary, FIXED across all four tabs (D-02/D-04)
- **Surface treatment:** translucent + compositor blur (`blur = true` + `ignore_alpha`), no background scrim (D-07/D-08)
- **Summon/dismiss:** Super+D toggles; Esc and click-outside both dismiss; keyboard focus grabbed on summon (`WlrKeyboardFocus.OnDemand` + `HyprlandFocusGrab`, QS-02-proven pattern reused verbatim) (D-09/D-10/D-12)
- **Coexistence:** focus-loss auto-dismiss only, zero edits to swaync/walker/wleave (D-13)
- **Lifecycle:** destroy-on-dismiss (`LazyLoader`), selected-tab memory + data backends persist at shell root (D-14)
- **Tabs:** Dashboard, Media, Performance, Weather — in that fixed order; header row with icon+label per tab, active indicator tracks swipe progress; `SwipeView`-class drag (~1/3 distance or flick, spring-back below threshold); arrow keys cycle CLAMPED (no wraparound) (D-15..D-19)
- **Entrance motion:** per-namespace layer-rule `slide` (open/close) + a summon-only staggered content cascade on the active tab only, never on tab switches, collapsing under reduced/off motion scale (D-20/D-21)
- **Namespace:** `quickshell-dashboard`, part of the `quickshell-*` family regex convention other QML surfaces inherit (D-42); overlay layer, zero exclusive zone, `hyprctl layers -j` empty when dismissed (D-43)
- **Fullscreen refusal (DASH-08):** silent no-op over TRUE fullscreen only; maximized windows do not block; no notification on refusal (D-11)
