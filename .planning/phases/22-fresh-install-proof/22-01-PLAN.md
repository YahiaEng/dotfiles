## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host → podman container | The harness runs an ephemeral `--rm` container with `-v "$LOG_DIR:/logs:Z"`; the container writes into a host directory. |
| public remote → container filesystem | `git clone --depth 1 https://github.com/yahiaeng/dotfiles` pulls repository content that the container then executes as `install.sh`. |
| container root → NOPASSWD sudoers drop-in | The in-container script creates `/etc/sudoers.d/builder-nopasswd` so `paru`/`makepkg` can run as a non-root user. |
