    `SWEEP_HOME`, emit a `[SKIP]` line naming the root and the reason "not present",

    meaningful.

    the declared recursion mode). A link is DANGLING if and only if full-chain
    resolution of it fails — resolve the entire chain, not one hop, so that a link
    landing on an existing intermediate whose own target is absent is still
    reported, and so that a symlink loop is reported as dangling rather than
    hanging the sweep. Use a resolver that fails on any missing component and on
    `ELOOP`; do not implement a hand-rolled one-hop existence test.

    Emit one `[FAIL]` line per dangling link, naming the link path relative to
    `SWEEP_HOME` and its unresolved target. Emit one `[PASS]` line per root that

    byte-order sort with `LC_ALL=C` set, so two runs over an unchanged tree produce

    provisional. Refuse to load an entry with an empty reason. Print every

    every run — never silently discard. Start the list EMPTY; add an entry only if
    a real sweep surfaces a link that is legitimately dangling by design, and write
    the reason at that moment.
