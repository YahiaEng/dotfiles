<objective>
Make `stow-link-check` measure what it claims to measure, and clear the three
dangling symlinks this repository is actually responsible for.

Purpose: plan 22-02 built a correct checker and pointed it at the wrong territory.
Run against the real dev host it reports 1095 findings, and the breakdown shows
only three of them are this repository's debt. Two defects produce the rest, and
one of them is phase-blocking: the checker fails on its own committed test
fixtures, which `stow.sh` deploys to `~/.config/hypr/scripts/tests/` on every
machine. Left alone, `theme-doctor` fails on every fresh install forever — and
plan 22-04's whole purpose is to make `theme-doctor` blocking inside the
container, so 22-04 could never go green.

The tempting wrong fix is to allowlist the fixtures. D-22-09 forbids it: allowlist
entries may only be derived from genuine session-dependent failures observed in a
real run. A deployed test fixture is not a session-dependent failure — it is the
checker scanning its own test data, and it belongs in the sweep's scope
definition, not in an allowlist.

Output: a checker whose declared scope and actual scope match, `--self-test` still
6/6, and a dev host with zero repository-caused dangling links.
</objective>
