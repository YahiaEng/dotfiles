<objective>
Make the fresh-install gate fast enough to actually use, without weakening what
it proves.

Purpose: the gate currently takes ~62 minutes, and the baseline plus the aborted
re-run have now each consumed roughly an hour without producing a verdict. A
reproducibility check that cannot be run twice in a session is not a verification
tool — it is a ceremony. Measurement identified where the time goes precisely, and
it is not spread thin: two icon-theme packages account for 43 of the 62 minutes,
and every run re-downloads and re-builds everything because the harness mounts
nothing but its log directory.

Two independent changes address it. Cutting the two icon themes out of
`--core-only` removes 43 minutes deterministically. Mounting host caches speeds up
what remains. They are complementary — the first removes work, the second speeds
up the work that is left.

Scope boundary: this plan changes only what the gate installs and how fast it
installs it. It does not touch the verdict logic, the step ledger, or anything
`theme-doctor` checks. Plan 22-07's task 3 re-run follows this plan and produces
the actual verdict.

Output: an `install.sh` whose container-gate scope is proportionate, a
`container-run.sh` that reuses host caches safely and can be told not to, and a
recorded before/after wall-clock measurement.
</objective>

<context>
Every figure below was measured directly, not estimated.

**Where the time goes.** Extracted from the baseline's `03-install.log` by
differencing consecutive `==> Making package:` timestamps:

| Package | Build time |
|---------|-----------|
| `tela-icon-theme` | 19:36:13 → 19:57:21 = **21 min** |
| `colloid-icon-theme-git` | 19:57:21 → 20:19:30 = **22 min** |
| `paru` (bootstrap) | 19:20:07 → 19:27:13 = 7 min |
| all ~30 other AUR packages combined | ≈ 11 min |

The cost is `package()` copying tens of thousands of small icon files onto
overlayfs. It is NOT compression — the image already ships
`COMPRESSZST=(zstd -c -T0 -)`, which is multi-threaded, and `PKGEXT='.pkg.tar.zst'`.
Do not waste effort tuning compression.

**Why cutting them is safe.** `hypr/.config/hypr/scripts/icon-theme-picker.sh`
discovers installed icon themes at runtime; line 125 explicitly handles "only
Adwaita installed locally" by offering to browse installable themes. No `.ini`,
`.lua`, `.toml`, `.conf` or `.qml` file in the repository names Tela or Colloid.
`papirus-icon-theme` remains a pacman package (`install.sh:193`) and is a fast
prebuilt binary, so icon theming still has a real theme present in the container.

**Current mount situation.** The harness runs
`podman run -v "$LOG_DIR:/logs:Z"` and mounts nothing else, so every run
re-downloads every source and rebuilds every AUR package from zero.

**Host cache sizes** — these are real state, not scratch: `/var/cache/pacman/pkg`
is 23 GB, `~/.cache/paru` is 8.4 GB.

**Known caching limitation, do not oversell it.** Cache hits key on package
version. `tela-icon-theme` is version-pinned and caches reliably.
`colloid-icon-theme-git` is a `-git` package whose `pkgver()` re-resolves against
upstream HEAD, so it rebuilds whenever upstream commits regardless of cache. This
is precisely why the scope cut in Task 1 is the load-bearing change and caching is
the supporting one — the two are not interchangeable.
</context>
