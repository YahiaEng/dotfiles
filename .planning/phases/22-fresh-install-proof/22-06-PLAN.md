<objective>
Run the graphical VM tier and record the human verdict that closes RETIRE-09.

Purpose (D-22-01 — both INST-03 tiers run; the container gate blocks and this
graphical tier follows): the container gate renders nothing. Every surface this milestone built —
the bar, the notification popups and centre, the OSD indicators, the power menu,
the dashboard drawer, the workspace overview, the Media tab with its cava ring — is
invisible to it. The reproduction procedure's own stated pass condition is that a
tool-only pass without human visual confirmation does not satisfy the requirement,
and the project's standing decision that a human render gate is load-bearing applies
here as it did to every migration phase in this milestone. The phase's first success
criterion names only the container tier; running the VM tier deliberately exceeds it.

Output: a recorded verdict with its exemptions and its evidence, and RETIRE-09
closed in the requirements and roadmap.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host → disposable VM | The host runs virtualisation tooling and defines a VM; the VM is a real machine with a real bootloader, not a container. |
| public remote → VM filesystem | The VM clones the repository over HTTPS and then executes `install.sh` unflagged with `sudo`, including the hardware section that installs files outside the home directory. |
| VM sudoers drop-in → the verification cycle's lifetime | The procedure creates a passwordless-sudo drop-in inside the VM so the installer runs unattended. |
| operator's report → the recorded verdict | The only input that can close the graphical tier is what the human says they saw. |
