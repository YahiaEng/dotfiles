<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MPRIS metadata → applet → backend | A player's D-Bus bus name is attacker-influenced. It is the ONLY metadata-derived string that ever goes near a command, and it is validated once by `_valid_id` inside `media-players.sh` — nowhere else. |
| slider values → backend | Seek/volume values are numeric slider outputs passed as argv, never interpolated into a shell string. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-03-01 | Tampering (command injection) | lib/media.ts → media-players.sh | medium | mitigate | The applet inherits the 08-07 contract: player ids come only from `media.player`/`players[].id` (already `_valid_id`-validated upstream); all backend calls are argv-form arrays; no title/artist/album metadata is ever passed as an argument. Low residual risk. |
| T-10-03-02 | Tampering | seek/volume numeric args | low | mitigate | Values are rounded numbers from `Gtk.Scale`, passed argv-form to the backend; `media-players.sh` validates verbs and exits 2 on any validation failure without calling playerctl. |
| T-10-03-03 | Denial of Service | long-lived `media-status.sh watch` subprocess | low | accept | One watcher subprocess per AGS instance; partial/malformed JSON lines are caught and ignored, never crashing the reader. |
</threat_model>
