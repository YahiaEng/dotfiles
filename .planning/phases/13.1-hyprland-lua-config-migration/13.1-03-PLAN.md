Close the three genuinely unverified questions this phase carries, using a live Lua-booted
compositor — the only place they can be answered — and then port the two declaration-only modules
whose Lua shape is already verified.

from documentation. They become answerable the moment plan `13.1-02`'s harness boots a nested Lua
instance. Answering them *before* the 923-line port — rather than discovering a wrong property
spelling as a silently-no-op window rule afterwards — is the whole reason the tracer came first.

Output: `13.1-LUA-FINDINGS.md` with an evidence table, `config/monitors.lua`,
`config/autostart.lua`, and an entry point that requires all seven modules.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
