## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing Critical Functionality] lua-table value extractor silently skipped every non-string leaf**
- **Found during:** Task 1
- **Issue:** 13.1-02's original implementation only emitted `key<TAB>value` for string-typed leaves. `motion.speed.*` (8 numeric values) and `motion.curves.*.points` (10 nested bezier-control-point arrays) were completely absent from the extracted value set — meaning theme-parity's Layer 3 "declared value must never render empty" check never actually validated roughly 18 of the token file's 50 real leaf values. The plan's own action text explicitly required this ("Non-scalar leaves ... should be emitted in a stable, deterministic textual form rather than skipped — a skipped value is a value the parity checker cannot compare").
- **Fix:** Added `is_array()`/`serialize()` helpers; every leaf (string, number, boolean, or array) now emits a value line, with array leaves serialized as a stable `[[0.2,0],[0,1]]`-style token.
- **Files modified:** theme-engine/.config/theme-engine/lib/contract.sh
- **Verification:** Live extraction went from 31 to 50 lines; every line still exactly two tab-separated fields; theme-parity 2785/0 unaffected (no false color-check trigger on numeric/array tokens, confirmed by regex inspection of Layer 3's malformed-color check).
- **Committed in:** `79fdff2` (Task 1 commit)

**2. [Rule 1 - Bug] lua-table name extractor leaked Lua array indices as bare key names**
- **Found during:** Task 1
- **Issue:** `pairs()` over a Lua array table (`points = {{0.2,0},{0,1}}`) returns integer keys 1/2 indistinguishably from a genuine named key — the original walker added every key, including these, to the name set. This diverges from the `toml`/`json` sibling branches, which never add a list index as a key (only dict/object keys contribute). Result: 2 spurious bare names (`1`, `2`) polluted every name-set comparison.
- **Fix:** Same `is_array()` helper reused in the names arm: array elements are still walked (for any further nested named keys) but their own integer index is never added to the name set.
- **Files modified:** theme-engine/.config/theme-engine/lib/contract.sh
- **Verification:** Live extraction went from 47 (with `1`/`2` noise) to 45 clean, deduplicated names; theme-parity's Layer 2 cross-target comparison for this file still passes across all 22 targets.
- **Committed in:** `79fdff2` (Task 1 commit)
