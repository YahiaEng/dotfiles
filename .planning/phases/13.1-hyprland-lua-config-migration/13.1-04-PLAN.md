<objective>
Port the remaining top-level option blocks and the entire keybind set — the half of the migration
that `hyprctl` can prove directly.

Purpose: `hyprctl -j binds` gives line-by-line coverage of 80 bind declarations, and
`hyprctl -j getoption` gives it for every option key. This is the largest chunk of the port where
correctness is *mechanically* checkable rather than visually checkable, so it is where the
equivalence gate earns most of its value. D-07 flags keybinds as one of the two files where a
mechanical translation is least trustworthy; the baseline is the answer to that.

Output: a complete `hl.config` surface in the entry point and a fully ported `config/keybinds.lua`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ported bind set → Quickshell global-shortcut registry | the two `global` binds carry identifier strings that must match the Quickshell `GlobalShortcut` manifest exactly; a renamed identifier silently unbinds a probe surface |
| ported bind set → privileged helper scripts | 35 `exec` binds launch scripts including screenshot, recording and clipboard tooling; a mangled command string changes what runs on a keypress |
| unverified API vocabulary → committed compositor config | a wrong dispatcher name or bind option under Lua's dynamic typing produces a silently dead bind rather than an error |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13.1-12 | Tampering | `config/keybinds.lua` command strings | high | mitigate | Every bind is diffed against the committed `hyprctl -j binds` baseline, which carries the resolved dispatcher and argument for all 80 binds — a mangled command string shows up as a diff, not as a surprise at keypress time. The `$variable` values are asserted byte-identical. |
| T-13.1-13 | Denial of Service | Quickshell probe surfaces | medium | mitigate | The two `global` dispatcher identifiers are asserted equal to the baseline by a `jq` query over both dumps, so a renamed shortcut cannot pass. `keybind-doctor` — the instrument built in Phase 11 precisely to catch bind-registration conflicts across the Hyprland and Quickshell mechanisms — must not regress. |
| T-13.1-10 | Spoofing (silent no-op) | dispatcher and bind-option names | high | mitigate | Names are cross-checked against `HL.DspNamespace` and `HL.BindOptions` in the vendor-shipped stub before being written, and the resulting registrations are read back from the compositor's own bind dump. Occurrence-count assertions for each bind option catch a whole flag class being dropped. |
| T-13.1-14 | Tampering | commented-out options | low | mitigate | `dwindle:pseudotile` and `misc:vfr` are asserted to read back as unset. Enabling a commented option would be a silent behaviour change disguised as a port. |
| T-13.1-SC | Tampering | npm/pip/cargo installs | low | accept | No package-manager install task exists in this plan. |
</threat_model>
