Expand the tracer's single compact card into the full popup experience: gestures, stack depth
management, in-place updates, progress rings, critical treatment, the icon fallback chain, and
safely-rendered body text.

weight. The phase deletes its predecessor with no soak window and no rollback, so `replaces_id`

repeatable fixture that is green before the render gate.

ownership. This plan is that criterion.

Output: a complete popup card and stack, plus a runnable fault-injection script.

      from the start.

      has one, and otherwise dismisses (D-19-10).
    - When the summed card heights would exceed the screen height clamp, the stack renders up to

      still counting against the height clamp like any other card.

  <action>
    Wire the in-place update through the wrapper's existing property-changed `Connections` block.
    Do not add an explicit "do not animate on replace" branch — the correct binding shape makes
    the no-reorder guarantee structural, and a suppression branch would mask the case where the
    assumption behind it turns out to be wrong. RESEARCH.md records that assumption as inferred
    rather than verified, which is exactly why Task 3's fixture exists: if the assumption is
    wrong the fixture goes red and the mechanism gets built explicitly, rather than shipping a
    silent stacking bug into a phase with no rollback.

    Draw the ring with the declarative shape/arc primitives the toolkit already ships, not a
    raster canvas redrawn every frame. Track colour from the capsule-track role, fill from the
    accent role, stroke from the ring-stroke token — all via `BarRoles`, never a direct palette
    reference. Clamp the incoming progress value into range before computing the sweep: the
    value arrives from an arbitrary session process and an unclamped huge number is a
    resource-exhaustion path, not just a rendering artefact.

    Create `NotifMarkdown.qml` as the allowlist filter: a function that escapes everything, then
    re-permits exactly bold, italic and link constructs, and returns a string safe to hand to the
    toolkit's markdown text format. It is a filter, not a parser — do not implement markdown
    grammar. Everything the allowlist does not name is escaped, which is the opposite of the
    usual denylist instinct and is the whole security property.

    Route the link hover through the bar's existing tooltip component so the raw URL is visible
    before any click, and gate the open behind an inline confirmation affordance in the existing
    capsule pill language. This is a named divergence from the reference shell, which opens links
    unconfirmed — justified because any process on the session bus can send a notification, so an
    unconfirmed click is a one-click launcher for a sender-chosen URL.
  </action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| session D-Bus → card rendering | Sender-controlled `summary`, `body`, `app_icon`, `image` and `hints` values reach text elements, an image loader, an icon resolver and an arc geometry computation. |
| card → external URL handler | A link inside sender-supplied body text can request that the shell open a sender-chosen URL. |

|-----------|----------|-----------|----------|-------------|-----------------|

Verified by Task 2's criterion that a heading, code fence, image construct and raw HTML tag all render literally. |
