<objective>
This plan is Phase 15's **tracer**: one production-quality path through every layer the
phase will touch, wired end to end and committed before any horizontal build-out begins.

`Super+A` → shell-root `openPanel("audio")` carrying the DASH-08 fullscreen guard →
`audioPanelLoader` → `PanelDialog` (the shared frame PANEL-06 asks for: header band,

click-outside dismissing to the desktop.

Purpose: prove the standalone-surface architecture on the agent's best early-context
tokens. Every later plan in this phase (15-03..15-09) and Phase 16's overview inherit
`PanelDialog`'s public surface and the single guarded summon path. An architectural
dead-end found here costs one commit; found after 15-04..15-08 have landed it costs six.

Output: three new QML types registered in `modules/dashboard/qmldir` in the same commit
that creates them, a fourth `GlobalShortcut` with its Hyprland bind and layer rule, and a
shell root whose every panel summon routes through one guarded function.

## Binding correction — `15-PATTERNS.md` is WRONG on one point

`15-PATTERNS.md` (the `shell.qml` section, around line 193) says the panels'
`GlobalShortcut` copies `dashboardShortcut` "minus the fullscreen-refusal guard, which
does not apply to panels", and its inline snippet writes
`onPressed: audioPanelLoader.active = !audioPanelLoader.active` with a comment saying
"no fullscreen guard".

**That is wrong and must not be followed.** REQUIREMENTS DASH-08 reads "Dashboard **and
panels** refuse to open over a fullscreen client", and ROADMAP Phase 14 criterion 5 reads
"neither the dashboard nor any panel opens over a fullscreen client."

**Resolution, binding on this plan and every later plan in the phase:** the DASH-08 guard
lives inside the single shell-root `function openPanel(name)`. Every summon path — this
plan's `Super+A`, 15-07's tile chevron, 15-08's waybar IPC call — calls `openPanel()`, so
the guard exists **exactly once** and no path can bypass it. `audioPanelShortcut.onPressed`
must not touch `audioPanelLoader.active` directly.

14-01's live finding applies unchanged: the guard blocks both maximize and true
fullscreen, because Hyprland 0.56.1 exposes no IPC signal anywhere that distinguishes the
two states (proven three independent ways in 14-01; see `shell.qml`'s own header comment
on `fullscreenBlocking`, which this plan leaves byte-unchanged).

## PANEL-02's `unresolved` edge row is owned by 15-04, not dropped

This plan cites PANEL-02, so the pointer is recorded here rather than left implicit: the
deterministic edge probe could not classify PANEL-02, and the protocol forbids
auto-`backstop`ping an `unclassified` row. The honest open edge — *whether writing
`preferredDefaultAudioSink` re-routes already-playing streams or only new ones* (RESEARCH
A2 / Pitfall 3) — is measured by 15-01, disposed at 15-01's `checkpoint:decision`, and
must appear **verbatim as an `unresolved` flagged assumption in 15-04's PLAN.md**. It is
not restated as a truth here and it is not dropped. This plan's PANEL-02 slice is master
volume and mute, which the A2 question does not touch.
