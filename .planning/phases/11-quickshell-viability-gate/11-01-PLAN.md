<assumption_delta_decision>
**Detector:** `assumption-delta scan 11` returned `detected: true`, `kind: pluralization` (signals: "alongside", "second", "fallback").

**What lost its monopoly:** global-keybind registration. Until this phase, a keybind on this machine had exactly one registration mechanism — a `bind =` line in `keybinds.conf`. Quickshell introduces a second, independent one (`GlobalShortcut` via `hyprland-global-shortcuts-v1`). `keybind-doctor`'s identity model is currently "a bind is a `(modmask,key,keycode,release)` tuple declared in keybinds.conf and registered in the compositor" — a noun that silently means *Hyprland bind*.

**Noun now primary:** **claimed chord** — a `(modmask, key)` pair with an *owner*, where owner ∈ {`hyprland-config`, `quickshell-globalshortcut`}.

**Decision: promote.** `keybind-doctor` (plan 02) is rebuilt around "claimed chord + owner", with the Hyprland `bind =` line demoted to one variant rather than the definition. This is the correct move because the whole reason MAINT-01 sits in Phase 11 is that Phases 14 and 16 each add a Quickshell-owned chord — an add-alongside model would leave the second mechanism permanently un-cross-checked.

**Accepted debt (add-alongside, one phase only):** the *themed surface* noun stays GTK-CSS-shaped (`contract.json` render target = a stylesheet file `@import`ing from `~/.local/state/theme/`). D-04 deliberately leaves this QML unstyled so the noun is not guessed. **What forces the promote:** Phase 12's TOKEN-01 — the first QML surface that must be themed promotes `contract.json`'s render-target noun from "stylesheet" to "render target of any format".

**Companion invariant test (suggested, non-blocking):** plan 02's poisoned-fixture proof (D-18) *is* this invariant test — it encodes "a chord claimed by either owner cannot be claimed by the other" as a gate that provably fails.
</assumption_delta_decision>
