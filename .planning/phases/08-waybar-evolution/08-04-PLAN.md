**Step A — confirm the event name and payload format empirically BEFORE wiring anything (Assumption A6).** The socket path is verified; the event name and payload are not. Record the exact lines observed. The expected shape is an `EVENT>>DATA` line naming fullscreen with a 1/0 payload — but do not assume it; parse what the compositor actually sends. Record the observed lines verbatim in the SUMMARY.

**Step B — write `hypr/.config/hypr/scripts/waybar-fullscreen-watch.sh`.** This is the first long-running socket-reading script in this repo — there is no structural analog, so follow only the house conventions (boxed header comment, strict mode, best-effort external calls) plus theme-doctor's inline-`python3` idiom.

Implementation requirements:
- Use **Python 3's stdlib `socket` module** via an inline `python3 - <<'PYEOF'` heredoc inside the bash wrapper. Python 3.14.6 is already installed. Do NOT add `socat` — it is not installed, and while it does exist in the official `extra` repo, the stdlib route costs zero new packages and this repo's package gate exists to keep that list honest.
- Resolve the socket path from `XDG_RUNTIME_DIR` + `HYPRLAND_INSTANCE_SIGNATURE`. If either is unset, or the socket does not exist, **exit 0 quietly** — there is no Hyprland session (e.g. the headless container gate). Never block, never spin.
- Connect, then read line-delimited events in a **blocking** read loop. On EOF (compositor exit) break and exit 0 cleanly. Do NOT wrap the read in an unconditional infinite loop — after the socket closes that spins the CPU at 100% forever.
- On a fullscreen-enter event, invoke `waybar-visibility.sh fullscreen hide`. On a fullscreen-exit event, invoke `waybar-visibility.sh fullscreen show`. Invoke with **argv as a list** (`subprocess.run([...])`), never `shell=True`, never a formatted command string — event payloads are compositor-supplied data and must never reach a shell.
- **Idempotency is required, not optional.** Hyprland's fullscreen event is documented (hyprwm/Hyprland#13041) to fire more than once per transition for some windows. The owner already absorbs redundant intents (it signals waybar only when the computed actuation changes), so re-declaring the same intent is harmless. Do not add de-duplication here that could swallow a genuine state change.
- Ignore every other event name. Do not parse window titles or class names out of the payload — nothing in this design needs them, and not touching them is the cheapest way to keep untrusted strings out of the process entirely.

**Step C — autostart.** Add an `exec-once` line to `hypr/.config/hypr/config/autostart.conf` launching the watcher through the repo's standard `uwsm app --` wrapper (every daemon-shaped process here is launched that way, for systemd scope isolation). Place it near the status-bar / idle-daemon entries, with a short section comment in the file's existing style naming BAR-01/D-01 as its provenance.
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hyprland event socket -> `waybar-fullscreen-watch.sh` | A long-running process reads an unbounded, compositor-supplied event stream. Event payloads can contain arbitrary window titles/classes set by any running application. |
| `hypridle.conf` `on-timeout`/`on-resume` -> shell | hypridle executes these as shell command strings with the session's privileges. |
| `keybinds.conf` `exec` -> shell | Hyprland executes the bind's command string with the session's privileges. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-20 | Tampering | socket2 event payload -> command execution | high | mitigate | The watcher matches only the fullscreen event name and its 1/0 state, and invokes the owner with a **fixed argv list** — no payload substring is ever interpolated into a command, and `shell=True` is prohibited. Window titles and classes (attacker-controllable by any running app) are never parsed at all. Asserted by a `grep -c 'shell=True'` == 0 criterion. |
| T-08-08 | Denial of Service | socket read loop after EOF | low | mitigate | Blocking read; break and exit 0 on EOF. No unconditional infinite loop around the read — that would spin a core at 100% for the rest of the session after the compositor exits. Asserted by a clean-exit-on-socket-close criterion. |
| T-08-21 | Denial of Service | fullscreen event storm | low | accept | Hyprland may fire the event several times per transition. The owner de-duplicates at the actuation layer (it signals waybar only on a computed state change), which bounds the blast radius to a few extra no-op subprocess spawns. Acceptable for a local desktop. |
| T-08-22 | Elevation of Privilege | `hypridle.conf` / `keybinds.conf` command strings | low | accept | These are repo-authored, static command strings invoking repo-owned scripts by absolute path with literal arguments. No external or user-supplied data is interpolated into them. Bounded by the same trust model as every other bind in this file. |
| T-08-SC | Tampering | npm/pip/cargo installs | high | mitigate | Not applicable — this plan installs no packages. The `socat` alternative was deliberately rejected in favour of the already-installed Python stdlib, keeping the dependency surface flat. |
</threat_model>
