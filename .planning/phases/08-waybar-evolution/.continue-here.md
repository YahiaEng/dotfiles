## Critical Anti-Patterns (do NOT repeat these)

| Pattern | Description | Severity | Prevention |
|---------|-------------|----------|------------|
| PUA-glyph stripping | Nerd Font private-use glyphs typed into Edit/Write get stored as **empty strings** (hit ~4× this phase: settings gear, font/icon glyphs, swaync theme toggle) | blocking | Write glyphs by codepoint via `python chr(0xNNNN)`, or JSON `\uXXXX`; always verify with a cmap/parse check afterward |
| `str.replace` matches ALL | Bulk `str.replace` on JSON/yuck hit the same substring in a second module twice (injected a Temp tooltip + htop into `custom/notification`; and the play-pause label) | advisory | Anchor replacements uniquely or use `count=1` + verify the diff |
| swaync `-rs` ≠ config reload | `swaync-client -rs` reloads **CSS only**; `config.json` changes (e.g. a toggle label) need `--reload-config` or a restart | advisory | Reload config when config.json changes, not just -rs |
| eww layer focus on Hyprland | Hyprland 0.55.4 does NOT give an eww overlay layer keyboard focus on open → `:unfocus-close`/`:onkeypressed` never fire; GTK `button` widgets fail to activate (focus-grab); fully-transparent backdrops are click-through | blocking | Use `:focusable false` + `eventbox` (not `button`) + a **scrim** backdrop for click-away; verify with the user (no click-injection tool available to self-test) |
