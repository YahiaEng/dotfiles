<objective>
Prove the cava-to-QML streaming contract end-to-end on real audio, then give the
stream a reference-counted owner with a short linger.

This is the phase's tracer. RESEARCH.md is explicit that **neither half has a local
precedent**: zero files in this repo use `SplitParser` (all 31 existing `Process`
call sites use `StdioCollector` for one-shot reads), and none of the 16
`pragma Singleton` files implements claim/release/counter ownership. Both halves
are assembled from the installed Quickshell 0.3.0-2 qmltypes contract plus two
structural analogs, not copied from a local file. Proving this slice first is what
stops the 60-bar ring, the cookie mask and the popout ring from all being built on
an unproven foundation.

Purpose: de-risk QMEDIA-02's only genuine unknown before any expansion task, and
land the ownership model D-21-06 requires (including its one-knob reversal clause).
Output: a new `cava/` stow package, a `CavaService` singleton both `modules/bar/`
and `modules/dashboard/` can reach, a linger constant, and one live bar on the
Media tab driven by real audio.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| QML shell → `cava` subprocess | The shell constructs an argv and spawns a process; anything user- or metadata-derived crossing into that argv is untrusted input to a command line. |
| `cava` stdout → QML parser | A continuous, attacker-influencable-in-principle byte stream (the audio device is shared) is parsed into an unbounded-by-default JS array inside the shell process. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-01 | Tampering | `CavaService.qml` `Process.command` | low | mitigate | argv is a fixed three-element list (binary, config flag, constant config path); no MPRIS metadata, track title, or other runtime-derived value may appear in any element. Asserted in Task 1's acceptance criteria as a source assertion. |
| T-21-02 | Denial of Service | `CavaService.qml` `SplitParser.onRead` | medium | mitigate | The parsed array is length-capped at the configured bar count before publication, so a malformed or overlong stdout line cannot drive unbounded allocation in the shell process. Blank/partial lines are dropped rather than published. |
| T-21-03 | Denial of Service | cava process lifecycle | low | mitigate | The refcount floors at 0 and the linger timer is non-repeating, so no path can leak a permanently-running process after every surface releases; verified by the idle-state process-count check. |
| T-21-SC | Tampering | package installs | low | accept | This plan installs no npm/pip/cargo package. `cava` is an already-installed official-repo pacman package re-verified this session (`cava 0.10.7-1`); `cava/` is a stow config-file package carrying no executable code. Package-legitimacy gate is not applicable in the registry sense. |
