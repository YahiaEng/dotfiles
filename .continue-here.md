## Decision waiting on you at resume

**DQ-1 — Super+Escape changes behaviour.** The plan rebinds it from `pkill walker` to
`systemctl --user restart quickshell.service`. Rationale recorded by the planner: the old
bind killed a separate on-demand process, whereas the replacement lives inside the
permanently-mounted shell; a process kill is wrong because the service file puts SIGTERM in
systemd's clean-exit exemption list (the bar would stay dead), and an IPC verb cannot recover
a wedged QML event loop — the exact failure D-03 guards.

**This is the only behaviour change in the whole 12-task plan.** It converts an
emergency-close key into a whole-shell restart. If you want something narrower, change it
**before T10** — that task rewrites `keybind-doctor` and five fixtures around the new
expression, so it is a one-line plan edit now and a multi-file unpick afterwards.
